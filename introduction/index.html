01. GapZer0 가이드라인 소개

01. GapZer0 가이드라인 소개

NIST CSF 2.0 기반 국내 정보보호 컴플라이언스 프레임워크

GapZer0는 NIST CSF 2.0과 ISMS-P를 연계하고 개인정보 보호법을 검토해, 국내 조직이 보안 요구사항을 함께 관리할 수 있도록 설계한 통합 프레임워크입니다. 이 가이드라인은 프레임워크의 Control을 실제 업무에서 이행하는 방법과 확인 자료를 안내합니다.

프레임워크 제작 배경과 목적

인증 이후에도 점검은 필요합니다

인증을 보유한 조직에서도 보안사고와 운영 결함이 발생합니다. Control이 실제로 이행되고 보안 목적을 달성하는지 지속적으로 확인해야 합니다.

국내 기준과 국제 목표를 연결합니다

NIST CSF 2.0과 ISMS-P를 매핑하고 개인정보 보호법을 검토했습니다. 공통 요구사항과 보완할 사항을 하나의 Control 체계로 정리했습니다.

이행 방법과 확인 자료를 제시합니다

Control별 Implementation Guide와 Evidence를 통해 수행할 활동과 확인할 자료를 안내합니다. 현재 상태를 점검하고 개선계획을 세울 수 있습니다.

프레임워크는 어떻게 만들었나요?

  1. 요구사항 매핑NIST CSF 2.0의 106개 Subcategory와 ISMS-P의 101개 인증기준을 세부 요구사항 단위로 비교했습니다. 대응관계는 Direct·Partial·Related·N/A로 구분하고 팀 내 교차검토를 거쳤습니다.
  2. Gap과 국내 고유 요구사항 식별ISMS-P만으로 CSF의 요구범위를 충분히 충족하기 어려운 영역과, CSF에 대응되지 않는 국내 고유 요구사항을 구분했습니다. 개인정보 보호법도 함께 검토했습니다.
  3. Control 설계공통 요구사항은 통합하고 부족한 사항은 보완하여 Common·Enhancement·Local의 121개 Control로 구성했습니다. 각 Control은 원본 기준과 연결해 설계 근거를 확인할 수 있도록 했습니다.

프레임워크 구성

15개 보안 영역에 121개 Control을 배치하고, 요구사항의 성격에 따라 세 유형으로 구분합니다.

어떤 정보를 제공하나요?

Control 이행 안내는 다음 항목으로 Control을 설명합니다.

항목제공 정보
Control ID · Control NameControl의 식별번호와 이름
Security Domain · Control Class보안 영역과 Control 유형
Control ObjectiveControl을 통해 달성하려는 보안 목적
Control Statement핵심 요구사항과 필요한 이유
적용 조건적용 시점·대상과 관련 법령
Control Owner · StakeholdersControl 책임자와 협업 주체
매핑된 ISMS-P · CSF 항목원본 기준과 Control의 연결관계
Implementation Guide실무자가 수행할 구체적인 이행 활동과 설명
EvidenceControl 이행을 확인할 수 있는 자료 예시
ISMS-P Limitation · CSF CoverageEnhancement Control에서 보완할 요구사항과 CSF 목표의 반영 내용

사용 대상

가이드라인은 ISMS-P 인증을 준비하거나 인증 취득 후 관리체계를 운영하는 국내 조직의 정보보호·개인정보보호 담당자를 위해 만들었습니다.

담당자는 기존 관리체계에서 Control의 이행 방법과 필요한 Evidence를 확인하고, 관련 부서와 보완할 사항을 정리할 때 이 가이드라인을 활용할 수 있습니다.

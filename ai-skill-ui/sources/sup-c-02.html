## SUP-C-02

### Control Name

외부 의존성 파악·전달

### Security Domain

Supplier Relationships Security

### Control Class

Common

### Control Objective

조직이 의존하는 외부 산출물·역량·서비스와 그 중요도를 파악하고 관련 부서에 전달하여 외부 의존성으로 인한 위험을 관리합니다.

### Control Statement

외부 의존성을 알지 못하면 장애·침해·계약변경 시 업무영향을 판단하기 어렵습니다. 조직은 공급자·클라우드·외부 서비스와 내부 업무·자산의 의존관계를 식별하고 최신 상태로 공유해야 합니다.

### 적용 조건

#### 적용 시점

외부 서비스 도입·변경·갱신 및 정기 자산·공급자 검토 시 적용합니다.

#### 적용 대상

핵심 업무·정보자산·시스템과 연결된 공급자·외부 서비스에 적용합니다.

#### 관련 법령

- [「개인정보 보호법」 제26조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=900079061) — 개인정보 처리업무를 외부에 위탁하는 경우 위탁 문서화·공개·수탁자 관리 등 관련 의무가 적용됩니다.

### Control Owner

구매·계약/공급자 위험관리 책임자

### Stakeholders

CISO, CPO, 법무, 업무부서, IT 운영, 재무, 감사, 공급자 담당자

### 매핑된 ISMS-P 항목

- 2.3.1 외부자 현황 관리
- 2.10.2 클라우드 보안
- 1.2.1 정보자산 식별

### 매핑된 CSF 항목

- GV.OC-05 — Outcomes, capabilities, and services that the organization depends on are understood and communicated

### Implementation Guide

#### 1. 외부 의존성 목록화

공급자·서비스·데이터·인터페이스와 담당자를 식별합니다.

#### 2. 내부 업무와 연결

각 외부 의존성이 지원하는 업무·자산·서비스와 중단 영향을 연결합니다.

#### 3. 중요도 분류

대체 가능성, 데이터 접근, 중단 영향 등을 기준으로 중요도를 정합니다.

#### 4. 관계부서 공유·갱신

의존성 정보를 자산·BCP·위험관리 담당자와 공유하고 변경 시 갱신합니다.

### Evidence

- **외부 의존성 목록:** 공급자와 내부 업무 연결을 확인합니다.
- **서비스·자산 구성도:** 기술적 의존관계를 확인합니다.
- **중요도 평가 기록:** 분류 근거를 확인합니다.
- **공유·변경 이력:** 최신 정보의 전달·유지를 확인합니다.

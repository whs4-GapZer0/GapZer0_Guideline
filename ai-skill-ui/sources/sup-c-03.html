## SUP-C-03

### Control Name

공급망 위험관리 체계 수립·합의

### Security Domain

Supplier Relationships Security

### Control Class

Common

### Control Objective

공급망 위험관리의 전략·목표·정책과 운영체계를 수립하고 주요 이해관계자와 합의하여 일관된 공급망 보안관리를 수행합니다.

### Control Statement

부서별로 공급자를 개별 관리하면 평가·계약·모니터링 기준이 달라질 수 있습니다. 조직은 공급망 위험관리의 범위, 원칙, 책임, 보고체계를 공식화해야 합니다.

최고경영자(CEO)와 경영진은 공급망 위험관리 정책·전략·목표를 승인합니다. 구매·계약 및 공급자 위험관리 책임자는 실무 수행·보고 및 승인사항의 이행 책임을 유지합니다.

### 적용 조건

#### 적용 시점

공급망 위험관리 체계 구축·개정, 중요 공급자 도입 시 적용합니다.

#### 적용 대상

조직의 정보·서비스에 접근하거나 핵심 기능을 제공하는 공급망에 적용합니다.

#### 관련 법령

- [「개인정보 보호법」 제26조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=900079061) — 개인정보 처리업무를 외부에 위탁하는 경우 위탁 문서화·공개·수탁자 관리 등 관련 의무가 적용됩니다.

### Control Owner

구매·계약/공급자 위험관리 책임자

### Stakeholders

최고경영자(CEO), 경영진, CISO, CPO, 법무, 업무부서, IT 운영, 재무, 감사, 공급자 담당자

### 매핑된 ISMS-P 항목

- 1.1.5 정책 수립
- 3.3.2 개인정보 처리업무 위탁

### 매핑된 CSF 항목

### Implementation Guide

#### 1. 범위·목표 정의

관리할 공급자 유형, 위험목표와 적용기준을 정합니다.

#### 2. 정책·절차 수립

선정·계약·운영·변경·종료 단계별 요구사항을 문서화합니다.

#### 3. 역할·보고체계 확정

구매·보안·법무·현업의 책임과 승인·보고 경로를 정합니다. 최고경영자(CEO)·경영진이 직접 검토·승인할 정책·전략·목표와 실무 책임자가 승인할 수 있는 운영 사항을 구분하여 문서화하고, 구매·계약 및 공급자 위험관리 책임자의 수행·보고·승인사항 이행 책임을 구분합니다.

#### 4. 승인·전달

최고경영자(CEO)·경영진이 공급망 위험관리 정책·전략·목표를 검토하고 승인합니다. 검토 의견과 승인 결과를 기록하고 관련자에게 시행기준을 전달합니다. 구매·계약 및 공급자 위험관리 책임자는 승인사항을 운영 절차에 반영하고 이행 결과를 보고합니다.

### Evidence

- **공급망 위험관리 정책·전략:** 범위·목표·원칙을 확인합니다.
- **절차·R&R:** 단계별 수행책임을 확인합니다.
- **승인·공지 기록:** 최고경영자(CEO)·경영진의 공급망 위험관리 정책·전략·목표 검토·승인과 관련자 대상 전달 및 후속 이행을 확인합니다.
- **사안별 승인권자와 승인 범위:** 경영진이 직접 승인할 사항과 실무 책임자가 승인할 수 있는 사항, 수행·보고 책임의 구분을 확인합니다.

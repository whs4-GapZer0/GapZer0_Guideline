## SUP-C-06

### Control Name

공급자·제3자 관계 체결 전 계획·실사 수행

### Security Domain

Supplier Relationships Security

### Control Class

Common

### Control Objective

공급자·제3자와 관계를 체결하기 전에 보안역량과 위험을 평가하여 수용 가능한 공급자를 선정하고 필요한 보호조치를 계약 전 결정합니다.

### Control Statement

계약 후 중대한 보안취약성이나 의존성을 발견하면 대체와 협상이 어렵습니다. 조직은 계약 전에 서비스 중요도, 접근범위, 보안역량과 사고이력을 확인해야 합니다.

### 적용 조건

#### 적용 시점

신규 공급자 선정, 중요 계약 갱신·범위 확대 전 적용합니다.

#### 적용 대상

정보·시스템·서비스에 접근하거나 핵심 기능을 제공할 후보 공급자에 적용합니다.

#### 관련 법령

- [「개인정보 보호법」 제26조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=900079061) — 개인정보 처리업무를 외부에 위탁하는 경우 위탁 문서화·공개·수탁자 관리 등 관련 의무가 적용됩니다.

### Control Owner

구매·계약/공급자 위험관리 책임자

### Stakeholders

CISO, CPO, 법무, 업무부서, IT 운영, 재무, 감사, 공급자 담당자

### 매핑된 ISMS-P 항목

- 2.3.1 외부자 현황 관리
- 2.3.2 외부자 계약 시 보안

### 매핑된 CSF 항목

- GV.SC-06 — Planning and due diligence are performed to reduce risks before entering into formal supplier or other third-party relationships

### Implementation Guide

#### 1. 평가범위 결정

서비스 중요도·데이터·접근권한·하위공급망을 파악합니다.

#### 2. 실사 수행

보안정책, 인증·점검결과, 사고이력, 기술·운영 역량을 확인합니다.

#### 3. 위험평가·선정

미흡 사항의 영향과 보완계획을 평가해 선정·조건부 승인·거절을 결정합니다.

#### 4. 계약 전 조치

필수 보완사항과 계약조건을 확정하고 승인 근거를 남깁니다.

### Evidence

- **사전 실사 체크리스트:** 평가범위와 검토항목을 확인합니다.
- **공급자 제출자료:** 보안역량 검증 근거를 확인합니다.
- **위험평가·선정 기록:** 선정 의사결정 근거를 확인합니다.
- **보완·계약조건:** 사전평가 결과의 반영을 확인합니다.

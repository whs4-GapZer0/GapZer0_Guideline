## SUP-C-04

### Control Name

공급망 참여자 역할·책임 수립·조정

### Security Domain

Supplier Relationships Security

### Control Class

Common

### Control Objective

조직과 공급망 참여자의 보안 역할·책임·권한을 명확히 정의하고 상호 조정하여 책임 공백과 중복을 방지합니다.

### Control Statement

공급망에서는 사고통보·접근통제·취약점 조치 등의 책임이 모호해질 수 있습니다. 조직은 내부 부서와 공급자의 책임경계를 계약과 운영절차에 명시하고 변경 시 조정해야 합니다.

### 적용 조건

#### 적용 시점

공급자 선정·계약·변경·갱신 및 책임변경 시 적용합니다.

#### 적용 대상

구매·보안·법무·현업과 공급자·수탁자 담당자에 적용합니다.

#### 관련 법령

- [「개인정보 보호법」 제26조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=900079061) — 개인정보 처리업무를 외부에 위탁하는 경우 위탁 문서화·공개·수탁자 관리 등 관련 의무가 적용됩니다.

### Control Owner

구매·계약/공급자 위험관리 책임자

### Stakeholders

CISO, CPO, 법무, 업무부서, IT 운영, 재무, 감사, 공급자 담당자

### 매핑된 ISMS-P 항목

- 2.3.2 외부자 계약 시 보안
- 3.3.2 개인정보 처리업무 위탁

### 매핑된 CSF 항목

- GV.SC-02 — Cybersecurity roles and responsibilities for suppliers, customers, and partners are established, communicated, and coordinated internally and externally

### Implementation Guide

#### 1. 공급망 활동 식별

평가·접근·변경·사고·종료 활동을 목록화합니다.

#### 2. 책임경계 정의

활동별 책임자·수행자·승인자와 공급자 책임을 정합니다.

#### 3. 계약·절차 반영

책임과 보고기한·연락체계를 계약·SLA·운영절차에 반영합니다.

#### 4. 변경 시 조정

조직·서비스·공급자 변경 시 책임 공백을 재검토합니다.

### Evidence

- **RACI·책임표:** 역할과 책임경계를 확인합니다.
- **계약·SLA:** 공급자 책임의 공식 반영을 확인합니다.
- **연락망·변경 기록:** 운영 중 책임의 유지관리를 확인합니다.

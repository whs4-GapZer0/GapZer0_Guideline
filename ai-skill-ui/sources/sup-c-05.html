## SUP-C-05

### Control Name

공급망 위험 대응 요구사항의 계약 통합

### Security Domain

Supplier Relationships Security

### Control Class

Common

### Control Objective

공급망 위험평가 결과와 보안 요구사항을 계약·협약에 반영하여 공급자가 조직이 요구하는 보안 수준을 이행하도록 합니다.

### Control Statement

평가에서 확인된 위험이 계약상 의무로 연결되지 않으면 실제 이행을 요구하기 어렵습니다. 조직은 접근통제, 사고통보, 점검권, 재위탁, 종료조치 등 필요한 보안 요구를 계약에 반영해야 합니다.

### 적용 조건

#### 적용 시점

신규 계약, 갱신, 중요 서비스 변경 시 적용합니다.

#### 적용 대상

조직 정보·시스템에 접근하거나 서비스를 제공하는 외부자 계약에 적용합니다.

#### 관련 법령

- [「개인정보 보호법」 제26조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=900079061) — 개인정보 처리업무를 외부에 위탁하는 경우 위탁 문서화·공개·수탁자 관리 등 관련 의무가 적용됩니다.

### Control Owner

구매·계약/공급자 위험관리 책임자

### Stakeholders

CISO, CPO, 법무, 업무부서, IT 운영, 재무, 감사, 공급자 담당자

### 매핑된 ISMS-P 항목

- 2.3.2 외부자 계약 시 보안

### 매핑된 CSF 항목

- GV.SC-05 — Requirements to address cybersecurity risks in supply chains are established, prioritized, and integrated into contracts and other types of agreements with suppliers and other relevant third parties

### Implementation Guide

#### 1. 위험 기반 요구사항 도출

사전평가 결과와 접근·데이터 범위에 따라 계약 요구를 정합니다.

#### 2. 계약조항 반영

보안의무, 사고통보, 감사·점검, 재위탁, 종료·반환·파기 조건을 명시합니다.

#### 3. 예외 승인

반영하지 못한 요구는 위험·대체조치·승인자를 기록합니다.

#### 4. 이행 추적

계약상 요구의 실제 수행과 위반·개선조치를 관리합니다.

### Evidence

- **위험평가·요구사항 목록:** 계약 요구의 근거를 확인합니다.
- **계약서·SLA:** 보안 요구의 법적·계약적 반영을 확인합니다.
- **예외·승인 기록:** 미반영 위험의 통제를 확인합니다.
- **이행점검 기록:** 계약 요구 준수를 확인합니다.

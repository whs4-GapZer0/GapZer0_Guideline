## SUP-C-07

### Control Name

공급자·제3자를 사고 계획·대응·복구에 포함

### Security Domain

Supplier Relationships Security

### Control Class

Common

### Control Objective

공급자 관련 사고가 발생할 때 조직과 공급자가 신속하게 협업하도록 공급자를 사고대응·복구 계획과 훈련에 포함합니다.

### Control Statement

외부 서비스 사고는 공급자 정보와 조치 없이는 원인분석·복구가 지연될 수 있습니다. 조직은 사고통보, 증거제공, 대응·복구 책임과 연락체계를 사전에 정해야 합니다.

### 적용 조건

#### 적용 시점

사고대응 계획 수립·훈련 및 공급자 계약·변경 시 적용합니다.

#### 적용 대상

사고 발생 시 대응·복구에 참여해야 하는 중요 공급자·제3자에 적용합니다.

#### 관련 법령

- [「개인정보 보호법」 제26조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=900079061) — 개인정보 처리업무를 외부에 위탁하는 경우 위탁 문서화·공개·수탁자 관리 등 관련 의무가 적용됩니다.

### Control Owner

구매·계약/공급자 위험관리 책임자

### Stakeholders

CISO, CPO, 법무 담당자, 업무부서, IT 운영 담당자, 재무 담당자, 감사 담당자, 공급자 담당자

### 매핑된 ISMS-P 항목

- 2.11.1 사고 예방 및 대응체계 구축
- 2.3.2 외부자 계약 시 보안
- 2.3.3 외부자 보안 이행 관리

### 매핑된 CSF 항목

- GV.SC-08 — Relevant suppliers and other third parties are included in incident planning, response, and recovery activities

### Implementation Guide

#### 1. 중요 공급자 식별

사고대응·복구에 필수적인 공급자를 정합니다.

#### 2. 협업절차 정의

통보시간, 연락망, 증거·로그 제공, 의사결정·복구 책임을 정합니다.

#### 3. 계획·계약 반영

사고대응계획과 계약·SLA에 협업 의무를 반영합니다.

#### 4. 훈련·개선

공급자가 참여하는 훈련 또는 절차 검증을 수행하고 미흡 사항을 개선합니다.

### Evidence

- **공급자 포함 사고대응계획:** 역할·연락·통보 기준을 확인합니다.
- **계약·SLA:** 사고협업 의무를 확인합니다.
- **훈련·사고 기록:** 실제 협업과 개선을 확인합니다.

GapZer0 AI Assistant

보안 업무 상황을 질문하면 GapZer0 가이드라인에서 필요한 보안 통제를 찾아 실행 방법과 문서 초안까지 제공합니다.

GapZer0 가이드라인을 직접 검색하지 않아도 조직의 보안 상황에 맞는 Control을 찾고, 통제 적용 방법과 이행계획, 실무 문서 초안 작성을 지원하는 AI Skill입니다.

Problem

보안 Framework와 Guideline에는 많은 Control이 있어 실무자가 자신의 상황에서 어떤 통제를 확인해야 하는지 찾기 어렵습니다.

Solution

GapZer0 AI Skill은 조직 상황에서 관련 Control을 찾고 실제 원문을 확인한 뒤 실무 적용을 지원합니다.

① 필요한 보안 통제 찾기

Control 안내

  • 관련 Control·Domain·Class
  • 관련 이유와 적용 조건
  • 주요 이행사항·추가 확인사항
  • Control ID와 Source

② 보안 통제 이행계획 만들기

이행계획

  • Control·목표·실행 활동
  • Owner·Stakeholders·Timing
  • Evidence·상태/비고
  • 추가 결정사항·Source

③ 실무 문서 초안 만들기

실무 문서 초안

  • 목적·적용 범위·역할과 책임
  • 업무 절차·기록/Evidence
  • 검토 및 개선·관련 Control

기본 출력 구조의 근거: output-formats.md. 조직에서 정해야 하는 값과 확보되지 않은 증적을 구분합니다.

RULES & SOURCES

AI Skill은 어떻게 동작하나요?

관련 후보를 찾는 것에서 끝나지 않고 실제 Control 원문과 조직 상황을 대조합니다.

  1. 사용자 요청해결할 보안 업무를 입력합니다.
  2. 요청 유형 판단안내·계획·문서 중 필요한 결과를 구분합니다.
  3. 필요한 조직 정보 확인결과에 꼭 필요한 정보만 확인합니다.
  4. Control Index 검색업무 대상·행위·위험에서 후보를 찾습니다.
  5. 실제 Control 원문 확인Index 요약만으로 요구사항을 확정하지 않습니다.
  6. 적용성 판단적용 조건과 사용자 상황을 비교합니다.
  7. 실무 결과 생성근거·제안·미확정 사항을 구분합니다.

GapZer0에서 AI Skill은 어디에 있나요?

Control을 찾고 적용하는 일을 돕는 단계이며, 실제 이행과 증적 평가는 별도 과정입니다.

FrameworkGuidelineAI SkillImplementationEvidenceGRC
전체 연결 상세 설명 보기
Framework
무엇을 관리해야 하는지 정의
Guideline
어떻게 이행할지 안내
AI Skill
필요한 Control을 찾고 적용을 지원
Implementation
조직에서 실제 수행
Evidence
수행 사실을 확인할 수 있는 자료
GRC
Evidence를 기반으로 평가·관리

이 연결은 프로젝트 역할 설명입니다. Web UI가 실제 이행이나 GRC 평가를 자동 실행하는 기능은 없습니다.

실증 환경 · Virtual Chibbo 보기

Virtual Chibbo의 합성 fixture를 사용해 Evidence XLSX 생성과 실제 GRC consumer/parser의 instance·Control 연결 및 평가 실행을 로컬에서 검증했습니다.

E03: D — local verification. 연결 대상은 TVM-C-06 / TVM-E-03입니다. 운영 S3·DB·API·UI 전체 파이프라인과 TVM-E-04는 미검증입니다. 평가 코드 실행 성공은 Control 전체 충족을 뜻하지 않습니다.

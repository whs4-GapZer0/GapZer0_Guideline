02. 가이드라인 활용 방법

Control을 이해하고, 현재 상태를 점검하며,
필요한 개선을 이어갑니다.

15개 보안 영역의 121개 Control을 조직의 업무와 시스템에 맞춰 활용하세요. 아래 순서로 이행 방법을 확인하고 평가 결과와 개선계획을 기록할 수 있습니다.

시작 전, 적용 범위를 정하세요

조직 전체 또는 특정 업무·서비스·시스템 중 점검할 범위를 정하고, 평가기간과 담당자를 확인합니다.

01

조직에 적용할 Control을 찾습니다

04. Control 이행 안내에서 보안 영역과 Control 유형을 선택합니다. 각 Control의 목적과 적용 조건을 읽고 조직의 업무·시스템에 해당하는지 확인하세요.

Common·Enhancement·Local은 Control의 도출 유형입니다. 인증 준비 시에도 Enhancement에 포함된 ISMS-P 요구사항을 함께 확인해야 합니다.

02

이행 방법과 확인 자료를 살펴봅니다

목적과 책임
Control Objective·Control Statement로 목적과 요구사항을 이해하고, Control Owner·Stakeholders로 책임자와 협업 대상을 확인합니다.
Implementation Guide
Control을 이행하기 위한 활동을 확인하고 조직의 절차와 시스템 환경에 맞게 수행합니다.
Evidence
이행 여부를 확인할 자료를 참고하여 실제 정책·설정·운영 기록 등을 살펴봅니다.
03

Control별 현재 상태를 평가합니다

05. 자가 진단에서 ‘자가진단 시작하기’를 선택합니다. 각 Control의 Implementation Guide 이행 상태와 실제로 확인한 증적을 바탕으로 평가하세요.

  • 충족
  • 부분 충족
  • 미충족
  • 적용 제외

평가 결과와 함께 평가 근거와 확인한 증적을 기록합니다. 적용 제외는 제외 사유를 남기고, 판단할 정보가 부족하면 결과를 선택하지 않은 채 추가 확인할 내용을 적습니다.

04

미흡한 사항을 개선하고 기록을 보관합니다

부분 충족·미충족 Control은 개선조치·조치 담당자·완료 예정일·진행 상태를 작성합니다. 개선 후에는 실제 이행 상태와 증적을 다시 확인하고 평가 결과를 갱신하세요.

브라우저에서 이어 쓰기
입력 내용은 서버가 아닌 현재 기기의 브라우저에 자동 저장됩니다. 같은 브라우저와 사이트 주소에서 이어서 작성하세요.
Excel로 보관·불러오기
‘작성 내용 Excel로 다운로드’로 입력한 Control을 보관합니다. 제공된 템플릿으로 작성한 파일은 ‘PC의 Excel 파일 불러오기’로 다시 불러올 수 있습니다.

브라우저 데이터를 지우기 전에는 Excel로 보관하세요. 파일 불러오기를 확정하면 현재 평가 전체가 교체되므로 기존 기록을 먼저 백업합니다.

작성 예시

작성 예시: 접근권한 관리

IAM-C-03접근권한의 부여·검토·회수와 최소권한·직무분리

아래 예시는 작성 방법을 설명하기 위한 가상의 현황과 기록입니다.

이행 가이드에서 무엇을 확인하나요?

직무별 권한 기준, 권한 신청·승인, 특수권한 관리, 응용프로그램·데이터베이스의 세부 권한, 인사변경 시 회수, 정기 적정성 검토가 수행되는지 확인합니다. 관련 Evidence를 참고해 정책과 실제 설정·운영 기록을 함께 살펴봅니다.

확인한 현재 상태

권한 기준과 승인절차가 마련되어 있고, 관리자 권한·응용프로그램·데이터베이스 권한 관리와 정기 검토를 수행하고 있습니다. 다만 이번 검토에서 직무변경자 2명의 이전 부서 다운로드 권한이 회수되지 않은 사실을 확인했습니다.

판단: 부분 충족 — 핵심 활동은 운영되고 있지만, 인사변경에 따른 권한 회수가 일부 미흡합니다.

  • 특수계정·관리자 권한 목록 및 사용기록 / 권한관리 시스템 / 2026년 3분기
  • 응용프로그램 접근권한 설정·데이터베이스 접근통제 설정 / 설정 점검 기록 / 2026-10-07
  • 퇴직·직무변경 권한 회수 기록·정기 접근권한 검토 결과 / 내부 문서함 ‘접근권한 관리’ / 2026년 3분기 및 2026-10-07 확인 기록
개선조치해당 2명의 불필요한 다운로드 권한을 즉시 회수하고 결과를 확인한다. 인사변경 통보부터 권한 회수 완료까지 확인하는 절차를 보완하고, 전체 직무변경자에게 유사한 잔존 권한이 있는지 추가 점검한다.

Information Protection Domain의 Common Controls는 저장된 데이터의 기밀성·무결성·가용성을 보호하기 위한 공통 요구사항을 제공합니다.

---

## INF-C-01

### Control Name

저장 데이터의 기밀성·무결성·가용성 보장

### Security Domain

Information protection

### Control Class

Common

### Control Objective

저장된 개인정보·중요정보와 업무데이터가 무단으로 열람·변경·삭제되거나 사용할 수 없게 되는 것을 방지하여 기밀성·무결성·가용성을 유지합니다.

### Control Statement

저장 데이터 보호를 암호화에만 의존하면 권한 오남용, 무단 변경, 매체 분실과 장애에 충분히 대응하기 어렵습니다. 조직은 데이터 중요도와 저장 위치를 파악하고 접근통제·암호화·무결성 확인·백업·매체보호를 함께 적용해야 합니다.

### 적용 조건

#### 적용 시점

데이터를 생성·수집·저장·이전하거나 저장소·권한·암호화 방식이 변경될 때 적용합니다. 정기 권한검토, 무결성 확인, 백업·복구와 저장매체 반출·폐기 시에도 적용합니다.

#### 적용 대상

데이터베이스, 파일서버, 업무용 단말·서버, 클라우드 저장소, 백업매체, 보조저장매체와 로그 등 저장된 개인정보·중요정보·업무데이터에 적용합니다.

#### 관련 법령

- [「개인정보 보호법」 제29조](https://www.law.go.kr/법령/개인정보보호법/제29조) — 개인정보 유출 등을 방지하기 위한 기술적·관리적·물리적 안전조치 의무를 규정합니다.
- [「개인정보의 안전성 확보조치 기준」 제7조](https://www.law.go.kr/행정규칙/개인정보의안전성확보조치기준/제7조) — 저장·전송되는 개인정보에 대한 암호화 조치를 규정합니다.
- [「개인정보의 안전성 확보조치 기준」 제11조](https://www.law.go.kr/행정규칙/개인정보의안전성확보조치기준/제11조) — 적용 대상 개인정보처리자의 재해·재난 대응절차와 백업·복구 계획 수립 등을 규정합니다.

### Control Owner

데이터 보호책임자 / 시스템 운영책임자

### Stakeholders

데이터·업무 소유자, 정보보호, 개인정보보호, DB·클라우드 운영, 백업복구, 개발, 내부감사

### 매핑된 ISMS-P 항목

- 2.7.1 암호정책 적용
- 2.7.2 암호키 관리
- 2.4.7 업무환경 보안
- 2.10.7 보조저장매체 관리

### 매핑된 CSF 항목

**PR.DS-01 — The confidentiality, integrity, and availability of data-at-rest are protected.**

저장된 데이터가 노출·변조·손실되지 않도록 기밀성·무결성·가용성을 보호하는 Outcome입니다.

### Implementation Guide

1. **보호 대상과 저장 위치를 파악합니다.**
   - 데이터 유형, 민감도, 소유자, 저장소·복제본·백업, 보유기간과 처리 목적을 목록화하고 보호수준을 정합니다.
2. **기밀성을 보호합니다.**
   - 업무상 필요한 최소 권한, 강한 인증, 저장 암호화, 키 분리관리와 출력·다운로드 제한을 적용합니다.
3. **무결성과 가용성을 보호합니다.**
   - 변경권한과 승인절차를 제한하고 해시·서명·감사기록 등으로 무단 변경을 확인하며 백업·이중화·복구방안을 운영합니다.
4. **보호상태를 점검하고 개선합니다.**
   - 권한, 암호화, 키, 저장매체, 무결성 경보와 백업상태를 정기 점검하고 기준 미충족 사항을 조치합니다.

### Evidence

- 데이터 분류·저장 위치·소유자 목록
- 접근권한·암호화·암호키 관리 설정
- 무결성 점검·변경·감사기록
- 백업·복구·저장매체 보호 및 점검기록

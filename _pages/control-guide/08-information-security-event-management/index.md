<div class="gz-domain-detail"><div class="gz-domain-overview"><p class="gz-domain-summary">Information Security Event Management는 정보시스템과 서비스에서 발생하는 보안 이벤트를 지속적으로 수집·모니터링·분석하고, 보안사고를 신속하게 식별하여 적절한 대응이 이루어지도록 관리하기 위한 보안 영역입니다.</p><p>로그와 이벤트가 충분히 수집·분석되지 않거나 사고의 판단·분류·보고 및 대응절차가 명확하지 않을 경우 침해 징후를 늦게 발견하고 대응이 지연되어 피해 범위가 확대되거나 사고의 원인과 영향을 정확하게 파악하기 어려울 수 있습니다.</p></div><aside class="gz-domain-goal" aria-label="보안 영역의 주요 목표"><strong>이 보안 영역의 목표</strong><p>따라서 이 보안 영역에서는 다양한 출처의 보안정보를 연계하여 이상행위를 탐지·분석합니다. 사고의 판단·분류부터 책임자 보고, 조사, 관련자 통지, 피해 확산 방지와 원인 제거까지 체계적으로 수행하여 보안사고의 영향을 최소화하는 것이 주요 목표입니다.</p></aside><h2 id="control-class">Control 유형별 이행 안내</h2><ul class="gz-class-list"><li><a href="{{ '/controls/information-security-event-management/common/' | relative_url }}"><h3>Common</h3><p>Common Control은 ISMS-P와 NIST CSF 2.0이 공통적으로 다루는 보안 목적과 Control 활동을 통합하여 구성한 기본 Control입니다.</p><span aria-hidden="true">→</span></a></li><li><a href="{{ '/controls/information-security-event-management/enhancement/' | relative_url }}"><h3>Enhancement</h3><p>Enhancement Control은 ISMS-P에서 충분히 다루지 못하는 NIST CSF 2.0의 보안 목적과 Control 활동을 보완하기 위해 구성한 Control입니다.</p><span aria-hidden="true">→</span></a></li></ul></div>

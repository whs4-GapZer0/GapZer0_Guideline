Supplier Relationships Security의 Local Control은 CSF에 직접 매핑되지 않은 국내 개인정보보호 요구사항을 반영합니다.

---

## 개인정보 제3자 제공

### Security Domain
Supplier Relationships Security

### Control Class
Local

### Control Objective
개인정보를 제3자에게 제공할 때 적법한 근거와 제공범위를 확인하고 정보주체의 권리를 보호하도록 제공합니다.

### Control Statement
조직은 개인정보 제3자 제공 전에 제공 목적·항목·대상·보유기간과 적법근거를 확인하고, 필요한 동의·고지·기록과 제공내역 관리를 수행해야 합니다.

### 적용 조건

#### 적용 시점
개인정보를 다른 개인정보처리자 등 제3자에게 제공하기 전과 제공조건 변경 시 적용합니다.

#### 적용 대상
개인정보 제3자 제공 업무와 제공받는 자에 적용합니다.

#### 관련 법령
확인 필요

### Control Owner
개인정보보호책임자(CPO) / 개인정보 처리업무 책임자

### Stakeholders
법무·컴플라이언스, 업무부서, 정보보호, 제3자 제공 담당자

### 매핑된 ISMS-P 항목
- 3.3.1 개인정보 제3자 제공

### 매핑된 CSF 항목
- N/A

### Implementation Guide

#### 1. 제공근거 확인
동의 또는 법적 근거와 제공 목적을 확인합니다.

#### 2. 최소범위 결정
목적에 필요한 개인정보 항목과 보유기간을 최소화합니다.

#### 3. 동의·고지 수행
필요한 사항을 정보주체에게 명확히 알리고 동의를 받습니다.

#### 4. 제공·기록 관리
승인된 대상·항목만 제공하고 제공내역과 변경·철회를 관리합니다.

### Evidence
1. **제3자 제공 현황:** 제공 대상·목적·항목을 확인합니다.
2. **동의·고지 자료:** 적법한 절차를 확인합니다.
3. **제공 승인·전송 기록:** 승인범위 준수를 확인합니다.
4. **제공내역 관리 기록:** 지속적 관리와 변경을 확인합니다.

## 영업의 양도 등에 따른 개인정보 이전

### Security Domain
Supplier Relationships Security

### Control Class
Local

### Control Objective
영업양도·합병 등으로 개인정보가 이전될 때 정보주체에게 필요한 사항을 알리고 이전받는 자가 개인정보를 적법하게 처리하도록 관리합니다.

### Control Statement
조직은 영업의 전부·일부 양도, 합병 등으로 개인정보를 이전하는 경우 이전 사실과 이전받는 자 등 법정 사항을 정보주체에게 알리고 안전한 이전과 후속 처리를 관리해야 합니다.

### 적용 조건

#### 적용 시점
영업양도·합병 등 개인정보 이전이 예정될 때 적용합니다.

#### 적용 대상
이전 대상 개인정보와 이전하는 자·이전받는 자에 적용합니다.

#### 관련 법령
확인 필요

### Control Owner
개인정보보호책임자(CPO) / 법무 책임자

### Stakeholders
경영진, 법무, 정보보호, IT 운영, 업무부서, 인수·양수 담당자

### 매핑된 ISMS-P 항목
- 3.3.3 영업양도 등에 따른 개인정보 이전

### 매핑된 CSF 항목
- N/A

### Implementation Guide

#### 1. 이전범위·근거 확인
이전 대상 정보와 거래구조·법적 요건을 확인합니다.

#### 2. 정보주체 통지
법정 사항·방법·시점에 따라 이전 사실을 알립니다.

#### 3. 안전한 이전
전송·매체·권한을 통제하고 이전 전후 데이터 무결성과 접근을 관리합니다.

#### 4. 이전 완료 검증
이전받는 자의 처리목적·보유·보호조치와 이전자의 잔존정보 처리를 확인합니다.

### Evidence
1. **이전 대상·계획:** 범위와 책임을 확인합니다.
2. **정보주체 통지 기록:** 법정 통지 이행을 확인합니다.
3. **이전·인수 기록:** 안전한 이전을 확인합니다.
4. **잔존정보·후속조치 기록:** 이전 완료 후 위험처리를 확인합니다.

## 개인정보 국외이전

### Security Domain
Supplier Relationships Security

### Control Class
Local

### Control Objective
개인정보를 국외로 제공·처리위탁·보관할 때 적법한 이전 근거와 보호조치를 확보하여 국외 처리 과정의 개인정보 위험을 관리합니다.

### Control Statement
국외 클라우드·수탁자 등으로 개인정보가 이전되면 관할·보호수준·재이전 등의 위험이 발생할 수 있습니다. 조직은 이전 유형과 법적 근거를 확인하고 필요한 고지·동의·계약·보호조치를 적용해야 합니다.

### 적용 조건

#### 적용 시점
개인정보의 국외 제공·처리위탁·보관을 신규 도입하거나 국가·수탁자·목적 등이 변경될 때 적용합니다.

#### 적용 대상
국외로 이전되는 개인정보, 국외 수령자·수탁자·클라우드 서비스에 적용합니다.

#### 관련 법령
확인 필요

### Control Owner
개인정보보호책임자(CPO)

### Stakeholders
법무·컴플라이언스, 정보보호, 구매·계약, IT·클라우드 운영, 업무부서

### 매핑된 ISMS-P 항목
- 3.3.4 개인정보 국외이전

### 매핑된 CSF 항목
- N/A

### Implementation Guide

#### 1. 이전현황 식별
국가, 수령자, 목적, 항목, 방법, 보유기간과 재이전 여부를 파악합니다.

#### 2. 적법근거 확인
국외이전 유형별 허용 근거와 필요한 동의·고지 요건을 검토합니다.

#### 3. 보호조치·계약
접근통제·암호화·사고통보·재이전 제한·삭제 등 필요한 조치를 계약과 기술구성에 반영합니다.

#### 4. 지속 관리
수령자·국가·서비스 변경과 사고·법적 변화가 발생하면 재검토하고 이전현황을 최신화합니다.

### Evidence
1. **국외이전 현황대장:** 국가·수령자·목적·항목을 확인합니다.
2. **법적 근거·동의·고지 기록:** 이전 적법성을 확인합니다.
3. **계약·보호조치 설정:** 실제 보호수준을 확인합니다.
4. **점검·변경 기록:** 지속적 관리와 재검토를 확인합니다.

## 관련 Framework

본 페이지의 Local Control은 GapZer0 Framework의 Supplier Relationships Security Domain 분석과 ISMS-P 및 NIST CSF 2.0 매핑을 기준으로 작성되었습니다.

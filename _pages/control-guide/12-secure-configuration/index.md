Secure Configuration은 서버, 단말, 네트워크 장비, 클라우드 자원 및 응용프로그램 등의 설정을 승인된 보안기준에 따라 안전한 상태로 유지하고, 허가되지 않은 설정 변경과 소프트웨어 실행을 방지하기 위한 Security Domain입니다. 보안 설정기준이 마련되지 않거나 시스템 설정이 임의로 변경되고 승인되지 않은 소프트웨어와 코드가 설치·실행될 경우 불필요한 기능과 취약한 설정이 공격에 악용되어 정보시스템의 침해 가능성이 높아질 수 있습니다. 따라서 이 Domain에서는 정보시스템 유형별 보안 설정기준을 수립·유지하고 설정 변경과 예외를 통제하며, 승인되지 않은 소프트웨어와 코드의 설치·실행을 제한하여 시스템이 지속적으로 승인된 보안상태를 유지하도록 하는 것을 주요 목표로 합니다.

## Control Class

### [Common]({{ '/controls/secure-configuration/common/' | relative_url }})

Common Control은 ISMS-P와 NIST CSF 2.0이 공통적으로 다루는 보안 목적과 통제 활동을 통합하여 구성한 기본 Control입니다.

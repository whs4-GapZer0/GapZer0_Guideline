Information Security Assurance는 조직이 수립·운영하는 정보보호 및 개인정보보호 관리체계와 보안통제가 의도한 목적에 맞게 설계되고 실제로 효과적으로 작동하는지 확인하기 위한 Security Domain입니다. 정책과 통제가 형식적으로만 존재하거나 점검·검증·감사 과정이 충분하지 않을 경우 운영상의 결함과 미준수 사항이 장기간 발견되지 않아 반복적인 보안문제와 통제 공백으로 이어질 수 있습니다. 따라서 이 Domain에서는 관리체계와 보안통제의 이행 상태와 효과성을 정기적으로 점검·검증하고, 발견된 문제와 개선사항을 추적하여 조직의 정보보호 수준이 지속적으로 유지·향상되도록 하는 것을 주요 목표로 합니다.

## Control Class

### [Common]({{ '/controls/information-security-assurance/common/' | relative_url }})

Common Control은 ISMS-P와 NIST CSF 2.0이 공통적으로 다루는 보안 목적과 통제 활동을 통합하여 구성한 기본 Control입니다.

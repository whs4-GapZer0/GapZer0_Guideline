Human Resource Security Domain의 Common Control은 인사 전 주기의 보안 통제, 전사 보안 인식 및 전문 역할별 직무 역량 관리를 위한 공통 요구사항을 제공합니다.

---

## 인사 전 주기에 사이버보안 통합

### Control ID

GZ-HRS-001 

### Security Domain

Human Resource Security

### Control Class

Common

### Control Objective

채용·업무 시작·직무변경·휴직·퇴직·계약종료 등 인사 전 과정에 사이버보안 책임과 통제를 포함하여, 사람과 역할 변화로 인한 정보·자산·접근권한 위험을 적시에 관리합니다.

### Control Statement

인사 정보가 보안·IT 운영과 연결되지 않으면 주요 직무자 지정, 보안서약, 접근권한 조정, 자산 반납과 위반 조치가 늦거나 누락될 수 있습니다. 조직은 임직원·임시직원·외부자의 고용·계약 상태와 역할 변화에 따라 필요한 보안 활동과 책임을 인사 절차에 포함하고 결과를 확인해야 합니다.

### 적용 조건

정보자산에 접근하거나 관리체계 범위의 업무를 수행하는 임직원, 임시직원, 파견·외주 인력과 관련 관리자에게 적용합니다. 조직의 실제 고용·계약·직무변경 유형에 따라 해당 절차를 적용합니다.

### Control Owner

인사 책임자 / 정보보호 책임자

### Stakeholders

각 부서장, IT·IAM 운영, 개인정보보호, 법무·컴플라이언스, 구매·외부자 관리, 교육담당

### 매핑된 ISMS-P 항목

2.2.1, 2.2.3, 2.2.5, 2.2.6

### 매핑된 CSF 항목

GV.RR-04

### Implementation Guide

1. **인사 이벤트별 보안 활동과 책임을 정한다.** - 채용·계약, 업무 시작, 주요 직무 지정, 직무·부서 변경, 휴직, 퇴직·계약종료별로 알림 주체, 처리기한, 자산·계정·권한·서약·교육·점검 항목과 완료 확인 책임을 정의한다.
2. **주요 직무와 보안 의무를 반영한다.** - 개인정보·중요정보 취급과 주요 시스템 운영 등 주요 직무 기준을 정하고 대상자를 최소한으로 지정·현행화하며, 업무 특성에 맞는 보안·비밀유지 의무를 서약과 계약에 반영한다.
3. **역할 변화와 종료를 신속히 공유·처리한다.** - 인사변경 정보를 인사·정보보호·개인정보보호·IT·업무부서에 전달하여 계정·접근권한을 회수·조정하고 자산·출입증을 반납하며 결과를 확인한다.
4. **위반과 미완료 사항을 관리한다.** - 보안 의무 위반의 조사·소명·조치 절차를 적용하고, 인사 이벤트별 미완료·지연·예외를 추적하여 원인과 통제 개선사항을 반영한다.

### Evidence

- 인사 전 주기 보안 절차·체크리스트: 인사 이벤트별 역할, 처리항목과 완료확인 기준을 확인할 수 있는 자료.
- 주요 직무자·개인정보취급자 목록: 지정 근거, 최소화와 변경 이력을 확인할 수 있는 자료.
- 보안·비밀유지 서약 및 계약 조항: 업무 특성에 따른 책임과 준수 의무를 확인할 수 있는 자료.
- 인사변경 통보·계정·권한·자산 처리기록: 역할 변화와 종료 시 회수·조정·반납 결과를 확인할 수 있는 자료.
- 위반·예외·미완료 조치기록: 조사·소명·처리와 재발방지 활동을 확인할 수 있는 자료.

## 전사 인력의 기본 사이버보안 인식과 안전한 업무 수행 역량 확보

### Control ID

GZ-HRS-002 

### Security Domain

Human Resource Security

### Control Class

Common

### Control Objective

모든 임직원과 관련 외부자가 일상 업무의 사이버보안 위험을 이해하고 기본 보호수칙을 적용할 지식과 기술을 갖추도록 하여, 사람의 실수와 부주의로 인한 사고 가능성을 줄입니다.

### Control Statement

정책을 배포하는 것만으로는 피싱, 자격증명 유출, 부적절한 정보공유와 사고 미신고를 예방하기 어렵습니다. 조직은 대상과 업무위험에 맞는 인식제고·교육 계획을 수립·운영하고, 이수와 효과를 평가하여 다음 활동을 개선해야 합니다.

### 적용 조건

관리체계 범위의 모든 임직원과 정보자산에 직·간접적으로 접근하는 임시직원·파견·외주 인력에 적용합니다. 신규 인력은 업무 시작 전 필요한 기본 교육을 받도록 합니다.

### Control Owner

정보보호 교육책임자 / 인사·교육 책임자

### Stakeholders

각 부서장, 개인정보보호, 법무·컴플라이언스, IT 운영, 외부자·수탁자 관리, 내부감사

### 매핑된 ISMS-P 항목

2.2.4

### 매핑된 CSF 항목

PR.AT-01

### Implementation Guide

1. **연간 인식제고·교육 계획을 수립한다.** - 대상, 시기, 내용, 방법, 담당자와 필요한 자원을 정하고 조직의 주요 위협, 정책, 법규, 사고·점검 결과와 교육대상 특성을 반영해 승인받는다.
2. **기본 보안역량을 교육한다.** - 계정·인증정보 보호, 피싱·악성코드 대응, 개인정보·중요정보 취급, 기기·원격근무 보안, 사고·의심행위 신고 등 일반 업무에서 필요한 지식과 행동을 실제 사례와 함께 제공한다.
3. **입사·계약·변화 시 교육한다.** - 신규 인력과 외부자는 업무 시작 전에 교육하고, 관련 법규·정책·위협·업무 방식에 중대한 변화가 있으면 해당 대상에게 추가 교육과 안내를 제공한다.
4. **이수와 효과를 평가·개선한다.** - 대상자 대비 이수 여부를 확인하고 평가·훈련·신고지표·사고 및 점검 결과를 이용해 이해도와 행동 변화를 평가하여 미이수·취약 영역을 보완한다.

### Evidence

- 연간 인식제고·교육 계획과 승인기록: 대상, 일정, 내용, 방법, 책임과 자원 배정을 확인할 수 있는 자료.
- 교육자료·캠페인·훈련 콘텐츠: 일반 업무위험과 조직 정책을 다룬 교육 내용을 확인할 수 있는 자료.
- 대상자·이수·미이수 조치 기록: 임직원·외부자와 신규 인력의 교육 참여 및 후속 조치를 확인할 수 있는 자료.
- 효과성 평가·개선 기록: 평가, 모의훈련, 신고·사고 지표와 다음 계획 반영을 확인할 수 있는 자료.

## 전문 역할별 사이버보안 지식과 직무 수행 역량 확보

### Control ID

GZ-HRS-003 

### Security Domain

Human Resource Security

### Control Class

Common

### Control Objective

사이버보안 관련 전문 역할 수행자가 담당 업무의 위험과 보호조치를 이해하고 실행할 수 있는 직무별 지식·기술을 확보하도록 하여, 전문 업무의 오류와 통제 실패를 줄입니다.

### Control Statement

전사 공통 교육만으로는 관리자, 개발자, 보안운영자, 개인정보취급자 등 전문 역할의 판단과 기술적 업무를 충분히 지원하기 어렵습니다. 조직은 역할·권한·업무위험에 필요한 역량을 정의하고 직무별 교육·훈련과 효과 확인을 통해 전문성을 유지해야 합니다.

### 적용 조건

정보보호·개인정보보호, IT·클라우드·네트워크 운영, 개발·배포, 주요 시스템 관리, 사고대응, 감사·위험관리 등 사이버보안 관련 전문 역할과 주요 직무자에게 적용합니다.

### Control Owner

정보보호 책임자 / 해당 전문조직 책임자

### Stakeholders

인사·교육, 개인정보보호, IT·클라우드 운영, 개발·DevSecOps, 사고대응, 내부감사, 업무부서장

### 매핑된 ISMS-P 항목

2.2.4

### 매핑된 CSF 항목

PR.AT-02

### Implementation Guide

1. **역할별 역량 요구를 정의한다.** - 각 전문 역할의 업무·권한·기술환경·법적 책임과 관련 위험을 분석하여 필요한 지식·기술·경험, 교육 주제와 숙련 수준을 정한다.
2. **직무별 교육·훈련 계획을 수립한다.** - 공통 교육과 구분되는 기술·절차·법규·도구 교육, 실습·훈련, 자격·세미나 등 적합한 방법을 선택하고 역할·위험·변화에 따라 우선순위를 정한다.
3. **업무 시작과 변화에 맞춰 역량을 확보한다.** - 신규 지정·직무변경 시 필요한 교육을 제공하고, 기술·위협·법규·시스템이 달라지면 해당 역할의 교육내용을 갱신한다.
4. **직무 수행능력과 효과를 확인한다.** - 시험, 실습, 작업검토, 훈련 결과와 사고·점검 결과를 활용해 역량 충족 여부를 확인하고 부족한 영역의 보완교육과 업무 지원을 시행한다.

### Evidence

- 역할·역량 매트릭스: 전문 역할별 업무, 권한, 필수 지식·기술과 숙련 수준을 확인할 수 있는 자료.
- 직무별 교육·훈련 계획과 콘텐츠: 역할 위험과 기술환경에 맞춘 교육 내용을 확인할 수 있는 자료.
- 이수·자격·실습·훈련 기록: 대상자가 필요한 교육과 훈련을 수행했는지 확인할 수 있는 자료.
- 역량·효과 평가 및 보완 기록: 평가 결과, 부족 영역, 보완교육과 업무 지원을 확인할 수 있는 자료.

## 관련 Framework

본 페이지의 Common Controls는 GapZer0 Framework의 Human Resource Security Domain과 ISMS-P 및 NIST CSF 2.0 매핑을 기준으로 작성되었습니다.

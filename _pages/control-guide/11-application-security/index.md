Application Security는 조직이 개발하거나 도입하여 운영하는 응용프로그램과 서비스가 설계, 개발, 시험, 배포 및 변경 과정에서 보안위험에 노출되지 않도록 보호하기 위한 Security Domain입니다. 보안요구사항이 개발과 변경 과정에 충분히 반영되지 않거나 소스코드, 외부 구성요소 및 배포 전 검증이 적절히 수행되지 않을 경우 취약점이 운영환경에 포함되어 비인가 접근, 정보유출 및 서비스 침해로 이어질 수 있습니다. 따라서 이 Domain에서는 응용프로그램의 수명주기 전반에 보안요구사항과 검증활동을 통합하고, 개발·시험·배포 과정에서 발생할 수 있는 취약점과 변경위험을 사전에 식별·관리하여 안전한 응용프로그램을 운영하는 것을 주요 목표로 합니다.

## Control Class

### [Enhancement]({{ '/controls/application-security/enhancement/' | relative_url }})

Enhancement Control은 ISMS-P에서 충분히 다루지 못하는 NIST CSF 2.0의 보안 목적과 통제 활동을 보완하기 위해 구성한 Control입니다.

Application Security는 조직이 개발·도입·변경하는 응용프로그램과 소프트웨어에 필요한 보안활동을 기획·설계·개발·시험·배포 등 개발 전 과정에 반영하기 위한 Security Domain입니다. 개발 초기의 보안요구사항 정의부터 설계·구현·시험·배포까지 보안검토와 검증이 일관되게 수행되지 않을 경우 취약점이 발견되지 않은 상태로 운영환경에 반영되어 비인가 접근, 정보유출 및 서비스 침해로 이어질 수 있습니다. 따라서 이 Domain에서는 개발 단계별로 필요한 보안활동을 체계적으로 적용하고, 보안검토·시험·취약점 조치의 수행 여부와 효과를 지속적으로 확인·개선하여 안전한 소프트웨어 개발체계를 유지하는 것을 주요 목표로 합니다.

## Control Class

### [Enhancement]({{ '/controls/application-security/enhancement/' | relative_url }})

Enhancement Control은 ISMS-P에서 충분히 다루지 못하는 NIST CSF 2.0의 보안 목적과 통제 활동을 보완하기 위해 구성한 Control입니다.

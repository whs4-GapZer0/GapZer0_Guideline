<div class="gz-domain-detail"><div class="gz-domain-overview"><p class="gz-domain-summary">System and Network Security는 조직의 네트워크와 정보시스템이 비인가 접근, 오용, 외부 침입, 잘못된 연결 및 보안설정으로 인해 침해되지 않도록 보호하기 위한 보안 영역입니다.</p><p>조직의 정보시스템은 온프레미스 환경뿐 아니라 클라우드, 무선 네트워크, 원격접근, 외부 공개 서버 등 다양한 환경과 연결되어 운영되며, 이러한 환경에서 네트워크 경계와 접근 경로가 명확하게 관리되지 않거나 업무상 필요 이상의 통신과 접근이 허용될 경우 외부 공격자 또는 비인가 사용자가 내부 시스템과 중요정보에 접근할 가능성이 높아질 수 있습니다.</p></div><aside class="gz-domain-goal" aria-label="보안 영역의 주요 목표"><strong>이 보안 영역의 목표</strong><p>따라서 이 보안 영역에서는 조직의 네트워크와 정보시스템에 대한 논리적 접근 경로를 식별하고, 업무 목적과 정보자산의 중요도에 따라 필요한 접근만 허용하도록 통제하는 것을 주요 목표로 합니다.</p></aside><h2 id="control-class">Control 유형별 이행 안내</h2><ul class="gz-class-list"><li><a href="{{ '/controls/system-network-security/common/' | relative_url }}"><h3>Common</h3><p>Common Control은 ISMS-P와 NIST CSF 2.0이 공통적으로 다루는 보안 목적과 Control 활동을 통합하여 구성한 기본 Control입니다.</p><span aria-hidden="true">→</span></a></li></ul></div>

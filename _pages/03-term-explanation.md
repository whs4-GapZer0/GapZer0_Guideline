GapZer0 가이드라인과 Control Guide에서 사용하는 주요 용어를 설명합니다. 각 용어는 Framework와 가이드라인을 동일한 기준으로 이해하고 적용하기 위한 공통 기준입니다.

## Security Domain

GapZer0 Framework에서 유사한 보안 목적과 활동을 묶어 분류하기 위한 보안 영역입니다. 각 Control은 해당 보안 활동의 성격에 따라 Security Domain에 배치됩니다.

## Control

조직이 특정 보안 목적을 달성하기 위해 수행해야 하는 관리적·기술적·물리적 활동입니다. GapZer0 가이드라인에서는 각 Control별로 목적, 요구사항, 적용 조건, 책임 주체, 구현 방법 및 확인 가능한 Evidence를 제공합니다.

## Control Class

GapZer0 Control을 적용 성격에 따라 구분한 분류입니다. Control Class는 **Common, Enhancement, Local**로 구성됩니다.

### Common

국내 조직이 기본적인 보안관리체계를 구성할 때 공통적으로 검토할 수 있도록 구성한 기본 Control입니다. 기존 ISMS-P 요구사항과 NIST CSF의 보안 결과 사이에서 공통적으로 다루어지는 보안 목적과 활동을 중심으로 구성합니다.

### Enhancement

기존 국내 보안관리체계에서 일부 관련 요구사항은 확인되지만, NIST CSF의 보안 결과를 충분히 반영하기 위해 추가적인 보완이 필요한 영역을 구체화한 Control입니다. 기존 통제를 대체하기보다 부족한 범위나 활동을 보완하는 데 목적이 있습니다.

### Local

국내 법·제도 및 개인정보보호 환경 등 국내 조직이 별도로 고려해야 하는 요구사항을 반영하기 위한 Control입니다. NIST CSF와 직접 대응되지 않더라도 국내 환경에서 필요한 요구사항을 다룹니다.

## Control Objective

해당 Control을 통해 조직이 달성하려는 **보안 목적과 기대 결과**를 설명합니다. 구체적인 수행 절차보다는 Control이 궁극적으로 무엇을 보호하거나 개선하려는지를 이해하는 데 사용합니다.

## Control Statement

Control이 필요한 배경과 중요성, 조직이 충족해야 하는 핵심 요구사항을 설명합니다. 해당 Control을 이행하지 않을 경우 발생할 수 있는 위험과 조직이 수행해야 하는 주요 활동의 방향을 파악하는 기준으로 활용합니다.

## 적용 조건

해당 Control이 조직에 언제, 어떤 대상에 적용되는지를 확인하기 위한 정보입니다. 가이드라인에서는 필요한 경우 **적용 시점, 적용 대상, 관련 법령**을 제시하며, 실제 적용 여부는 조직의 업무·시스템·데이터·서비스 환경과 관련 요구사항을 고려하여 판단합니다.

## Control Owner

해당 Control의 구현, 운영, 유지 및 개선에 대해 주요 책임을 가지는 역할입니다. 실제 조직에서는 가이드라인에 제시된 역할을 참고하여 조직 구조와 업무 분장에 맞는 책임자를 지정합니다.

## Stakeholders

Control의 이행 과정에서 참여하거나 필요한 정보를 제공하고, 검토·협의·지원하는 관련 역할입니다. Control Owner와 협력하여 Control이 조직 내에서 실제로 운영될 수 있도록 지원합니다.

## Implementation Guide

Control을 실제 조직 환경에서 이행하기 위해 수행해야 하는 **핵심 이행 활동과 세부 실행 방향**을 설명합니다. 조직은 Implementation Guide를 참고하여 자신의 업무 절차, 시스템 환경 및 위험 수준에 맞게 구체적인 실행 방법을 정할 수 있습니다.

## Assessment Question

Control이 실제로 이행되고 있는지를 Self-Assessment에서 확인하기 위한 점검 질문입니다. 조직은 질문별 운영 상태와 관련 Evidence를 확인하여 현재 Control의 이행 수준을 판단합니다.

## Evidence

Control의 이행 여부를 객관적으로 확인하기 위한 **정책, 절차, 기록, 설정정보, 로그, 보고서 등 확인 자료**를 의미합니다. 가이드라인에 제시된 Evidence는 어떤 자료를 통해 Control의 이행 사실을 확인할 수 있는지 판단하는 기준으로 활용합니다.

## 평가 상태

Self-Assessment 결과를 표현하는 상태입니다.

- **충족**: 요구되는 활동이 이행되고 필요한 Evidence를 통해 확인할 수 있는 상태
- **부분 충족**: 일부 활동은 수행되고 있으나 대상, 절차, 기준 또는 운영 측면에서 보완이 필요한 상태
- **미충족**: 요구되는 활동이 구현 또는 운영되지 않은 상태
- **확인 필요**: 판단에 필요한 정보나 Evidence가 충분하지 않아 추가 확인이 필요한 상태
- **적용 제외**: 조직의 적용 범위나 업무 특성상 해당 Control이 적용되지 않으며 그 사유를 확인한 상태

## ISMS-P Limitation

해당 Control과 연결되는 ISMS-P 항목이 존재하더라도 GapZer0 Control이 요구하는 보안 목적이나 활동을 충분히 설명하지 못하는 부분을 정리한 항목입니다. 이를 통해 기존 국내 기준만으로는 명확하게 확인하기 어려운 보완 지점을 파악할 수 있습니다.

## CSF Coverage

해당 Control이 NIST CSF의 어떤 보안 결과를 보완하거나 반영하는지를 설명하는 항목입니다. 매핑된 CSF 항목과 함께 확인하여 GapZer0 Control이 어떤 CSF 결과를 다루는지 이해하는 데 활용합니다.

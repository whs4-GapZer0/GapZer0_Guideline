GapZer0 가이드라인은 조직에 필요한 Control을 선택하고, 이행 방법을 확인한 뒤, Evidence를 근거로 현재 상태를 평가하고 부족한 부분을 개선하는 방식으로 활용합니다. 개선 이후에는 다시 평가하여 조직의 보안 수준을 지속적으로 관리합니다.

## 활용 절차

1. **조직의 적용 범위를 설정합니다.**
2. **적용할 Control을 선택합니다.**
3. **Control의 요구사항과 Implementation Guide를 확인합니다.**
4. **필요한 Evidence를 확인합니다.**
5. **Self-Assessment를 수행합니다.**
6. **부분 충족·미충족 항목을 개선합니다.**
7. **개선 이후 다시 평가합니다.**

---

## 1. 적용할 통제 선택

먼저 조직에서 가이드라인을 적용할 범위를 정하고, 해당 범위에 필요한 Control을 선택합니다.

조직 전체를 대상으로 할 수도 있고 특정 서비스, 시스템, 업무 또는 조직 단위를 대상으로 적용할 수도 있습니다. 적용 범위를 정한 후 각 Control의 **Security Domain, Control Class, Control Objective, Control Statement 및 적용 조건**을 확인하여 조직에 적용할 Control을 식별합니다.

특히 적용 조건에서는 해당 Control이 필요한 시점과 적용 대상을 확인하고, 관련 법령이 제시된 경우 조직에 실제로 해당 법령이 적용되는지도 함께 검토합니다.

조직의 환경과 업무 특성상 적용되지 않는 Control은 임의로 제외하기보다 적용 제외 사유를 확인할 수 있도록 관리합니다.

---

## 2. 이행 방법 확인

적용할 Control을 선택했다면 해당 Control이 요구하는 보안 목적과 실제 이행 방법을 확인합니다.

먼저 **Security Objective**와 **Control Statement**를 통해 Control이 달성하려는 목적과 핵심 요구사항을 이해합니다. 이후 **Control Owner**와 **Stakeholders**를 확인하여 이행 책임자와 업무에 참여하거나 협조해야 하는 주체를 파악합니다.

실제 구현 시에는 **Implementation Guide**를 활용합니다. Implementation Guide에는 Control을 이행하기 위해 수행해야 하는 주요 활동과 세부적인 실행 방향이 제시되어 있으므로, 조직의 업무 절차와 시스템 환경에 맞게 적용합니다.

또한 **매핑된 ISMS-P 항목과 NIST CSF 항목**을 함께 확인하면 기존 보안관리체계와 GapZer0 Control의 관계를 파악하는 데 활용할 수 있습니다.

---

## 3. 현재 상태 평가

Control을 이행한 후에는 현재 조직이 해당 요구사항을 어느 수준까지 충족하고 있는지 확인합니다.

Self-Assessment의 **Assessment Questions**를 기준으로 실제 운영 상태를 점검하고, Control에 제시된 **Evidence**를 통해 이행 사실을 확인합니다. 단순히 정책이나 절차가 존재하는지만 확인하는 것이 아니라 실제 운영 결과를 확인할 수 있는 기록과 증적을 함께 검토합니다.

평가 결과는 다음 다섯 가지 상태로 관리합니다.

- **충족**: 요구되는 활동이 이행되고 필요한 Evidence를 통해 확인할 수 있는 상태
- **부분 충족**: 일부 활동은 수행되고 있으나 대상, 절차, 기준 또는 운영 측면에서 보완이 필요한 상태
- **미충족**: 요구되는 활동이 구현 또는 운영되지 않은 상태
- **확인 필요**: 판단에 필요한 정보나 Evidence가 충분하지 않아 추가 확인이 필요한 상태
- **적용 제외**: 조직의 적용 범위나 업무 특성상 해당 Control이 적용되지 않으며 그 사유를 확인한 상태

평가 시에는 결과만 기록하지 않고 판단 근거와 확인한 Evidence를 함께 남겨 이후 재평가와 개선 활동에 활용할 수 있도록 합니다.

---

## 4. 부족한 부분 개선

Self-Assessment 결과 **부분 충족, 미충족 또는 확인 필요**로 판단된 항목은 부족한 사항과 원인을 확인하고 개선 활동으로 연결합니다.

Implementation Guide를 다시 확인하여 수행되지 않았거나 충분하지 않은 활동을 식별하고, 필요한 정책·절차·기술적 조치·운영 방식 및 Evidence를 보완합니다. 개선 활동을 수행할 때에는 담당자와 필요한 협업 주체를 확인하고 개선 결과가 실제 Control의 목적을 충족하는지 검토합니다.

개선이 완료되면 관련 Evidence를 갱신하고 해당 Control을 다시 평가합니다.

---

## 5. 재평가 및 지속 관리

GapZer0 가이드라인의 활용은 최초 평가에서 끝나지 않습니다.

조직의 시스템, 서비스, 업무, 공급자 관계 또는 관련 요구사항이 변경되거나 새로운 보안 위험이 확인되는 경우 기존 Control의 적용 여부와 이행 상태를 다시 검토합니다. Framework 또는 가이드라인이 업데이트된 경우에도 변경된 Control과 Assessment 항목이 조직에 미치는 영향을 확인합니다.

재평가 결과 새롭게 확인된 부족사항은 다시 개선 활동으로 연결하고, 그 결과를 Evidence와 함께 관리합니다.

이를 통해 **Control 선택 → 이행 → 평가 → 개선 → 재평가**의 과정을 반복하여 조직의 보안 수준을 지속적으로 관리합니다.

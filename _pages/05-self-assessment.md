GapZer0 Framework의 Assessment Question을 이용하여 조직의 현재 상태를 평가합니다.

## 평가 기준

| 평가 | 의미 |
|---|---|
| 충족 | 요구사항이 모두 충족되고 객관적인 근거를 확인할 수 있음 |
| 부분 충족 | 요구사항의 일부가 미흡하거나 적용 범위·절차 등이 불완전함 |
| 미충족 | 요구사항을 이행하지 않음 |
| 적용 제외 | 조직 환경상 해당 요구사항이 적용되지 않음 |
| 확인 필요 | 현재 확보된 자료만으로 판단하기 어려움 |

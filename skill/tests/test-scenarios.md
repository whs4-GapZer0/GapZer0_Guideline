## 공통 평가 기준
- Control 선택 정확성
- Control ID / Name 정확성
- 원문 조회 여부
- 적용 조건 반영
- Implementation Guide 의미 보존
- Owner / Stakeholders 정확성
- Evidence 의미 보존
- 가이드라인 근거와 AI 제안 구분
- 확인 필요 / 조직 결정 필요 구분
- 근거 Control과 원문 위치 표시

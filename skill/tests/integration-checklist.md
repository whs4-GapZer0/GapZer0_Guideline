# GapZer0 AI Skill 통합 QA 체크리스트

## 자료 연결
- [ ] control-index의 모든 Control ID가 실제 원문에 존재한다.
- [ ] Control ID와 Control Name이 원문과 일치한다.
- [ ] Domain / Class가 원문과 일치한다.
- [ ] Source Path가 실제 Control 파일을 가리킨다.
- [ ] 검색 키워드가 Control 의미를 벗어나지 않는다.

## 요청 처리
- [ ] 사용자 요청 유형을 통제 안내 / 이행계획 / 문서 초안으로 구분한다.
- [ ] 필요한 조직 정보만 추가로 확인한다.
- [ ] 인덱스 검색 후 반드시 Control 원문을 확인한다.
- [ ] 관련 Control이 여러 개인 경우 근거 없이 하나로 확정하지 않는다.

## 결과 정확성
- [ ] 적용 조건이 원문과 모순되지 않는다.
- [ ] Owner / Stakeholders가 원문과 일치한다.
- [ ] ISMS-P / NIST CSF Mapping을 임의 변경하지 않는다.
- [ ] Implementation Guide의 의미를 보존한다.
- [ ] Evidence를 실제 보유 증적으로 오인하게 표현하지 않는다.
- [ ] 원문에 없는 주기·수치·승인 기준을 의무처럼 작성하지 않는다.

## 불확실성
- [ ] 부족한 자료는 '확인 필요'로 표시한다.
- [ ] 조직별 결정사항은 '조직 결정 필요'로 표시한다.
- [ ] AI의 실무 제안은 가이드라인 원문과 구분한다.
- [ ] 인증 가능 여부나 최종 컴플라이언스 충족 여부를 임의 판정하지 않는다.

## 추적성
- [ ] 답변에 관련 Control ID를 표시한다.
- [ ] Control 원문 위치를 표시한다.
- [ ] 인덱스와 원문 충돌 시 원문을 우선하고 충돌을 기록한다.

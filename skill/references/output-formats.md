# GapZer0 Skill Output Formats

이 문서는 같은 유형의 요청에서 핵심 항목이 빠지지 않도록 기본 출력 구조를 정의한다. 사용자의 요청에 따라 불필요한 항목은 줄일 수 있다.

## 1. 통제 안내

### 관련된 이유

## 2. 이행계획

### 대상 Control
- **Control ID / Name:**
- **목표:**

| 구분 | 내용 |
|---|---|
| 실행 활동 | Implementation Guide를 기준으로 실제 수행할 활동 |
| 담당 역할 | 원문의 Control Owner를 기준으로 작성 |
| 협업 역할 | 원문의 Stakeholders를 기준으로 작성 |
| 시점 | 원문 또는 사용자 제공 정보에 근거. 없으면 조직 결정 필요 |
| Evidence | 이행 확인에 필요한 자료 |
| 상태/비고 | 확인 필요 또는 조직 결정 필요 사항 |

### 추가 결정사항
조직이 별도로 정해야 하는 범위, 주기, 담당자, 승인 기준 등을 작성한다.

### 근거
관련 Control ID와 원문 위치를 표시한다.

---

## 3. 실무 문서 초안

# [문서명]

## 1. 목적
관련 Control의 Objective와 Statement를 바탕으로 작성한다.

## 2. 적용 범위
Control의 적용 조건과 사용자가 제공한 조직 범위를 반영한다.

## 3. 역할과 책임
Control Owner와 Stakeholders를 바탕으로 작성하되 실제 부서명은 사용자 정보가 있을 때만 확정한다.

## 4. 업무 절차
Implementation Guide를 업무 순서에 맞게 재구성한다.

## 5. 기록 및 Evidence
통제 이행 여부를 확인하기 위해 생성·보관할 자료를 정리한다. Evidence 예시는 이미 확보된 자료처럼 표현하지 않는다.

## 6. 검토 및 개선
원문에서 확인되는 검토·후속조치를 반영한다. 원문에 없는 주기를 임의로 추가하지 않는다.

## 7. 관련 Control
사용한 Control ID와 Name을 표시한다.

## 작성 시 표시 규칙
- **[가이드라인 근거]** 원문에서 직접 확인되는 요구사항
- **[AI 제안]** 실무 적용을 돕기 위한 제안
- **[확인 필요]** 자료 또는 조직 정보가 부족한 사항
- **[조직 결정 필요]** 조직이 자체적으로 확정해야 하는 사항

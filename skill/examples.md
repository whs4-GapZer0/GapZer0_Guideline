# GapZer0 AI Skill 사용 예시

> 아래 예시는 Skill의 처리 방식을 설명하기 위한 예시이다. 실제 Control ID와 원문 내용은 control-index 및 controls 연결 후 확정한다.

## 예시 1. 관련 Control 안내

**사용자**
> 퇴사자의 접근권한을 어떻게 관리해야 하나요?

**Skill 처리**
1. '퇴사', '접근권한', '계정 회수' 등의 업무 표현을 파악한다.
2. control-index에서 관련 Control 후보를 찾는다.
3. 후보 Control의 실제 원문을 읽는다.
4. 적용 조건을 사용자 상황과 비교한다.
5. 관련 Control과 선택 이유, 주요 이행사항, 추가 확인사항을 제시한다.

**주의**
Control ID는 인덱스와 원문 확인 전 임의로 생성하지 않는다.

## 예시 2. 이행계획

**사용자**
> 이 Control을 우리 조직에 적용할 이행계획을 작성해줘.

**Skill 처리**
Control 원문에서 Objective, 적용 조건, Owner, Stakeholders, Implementation Guide, Evidence를 확인한다.

**결과 형식**
- 대상 Control
- 목표
- 실행 활동
- 담당 역할
- 협업 역할
- 시점
- Evidence
- 조직 결정 필요 사항
- 근거 원문

원문에 수행 주기가 없다면 임의로 '월 1회' 등의 값을 확정하지 않는다.

## 예시 3. 실무 문서 초안

**사용자**
> 공급자 보안관리 절차 초안을 작성해줘.

**Skill 처리**
1. 공급자 보안관리와 관련된 Control 후보를 탐색한다.
2. 실제 Control 원문과 적용 조건을 확인한다.
3. 관련 Control이 여러 개인 경우 각각의 관련 이유를 확인한다.
4. 원문을 바탕으로 목적, 범위, 역할과 책임, 절차, 기록/Evidence, 검토·개선 항목을 구성한다.
5. 가이드라인 근거와 AI 제안, 조직 결정 필요 사항을 구분한다.

실제 Control ID와 세부 요구사항은 controls 연결 후 검증한다.

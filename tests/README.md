# Self-assessment 검증 및 유지보수

## 범위

이 페이지는 가이드라인의 자가 진단 작성 템플릿입니다. 계정·서버·파일 업로드·공동 편집·점수 집계·CSV 가져오기는 없습니다. 브라우저에는 최신 입력만 저장하고 내용을 입력한 질문만 CSV로 다운로드합니다. 빈 템플릿 CSV는 전체 489개 질문을 포함합니다. 빈 템플릿 다운로드는 저장된 평가를 변경하지 않습니다.

작성 항목은 기존 합의대로 담당자 응답, 판단 근거, 확인한 증적, 개선조치와 평가 기본정보를 유지합니다. 참고한 CSF Organizational Profile의 별도 Tier나 우선순위 필드는 추가하지 않습니다.

## 구성

- `_pages/05-self-assessment.md`: 담당자 작성 안내와 입력 화면 진입점
- `assets/assessment/questions.json`: 121개 Control·489개 질문과 Evidence 안내. 평가 질문 목록 원본은 담당자가 편집한 엑셀이며 가이드라인 기준 커밋은 sourceCommit에 기록합니다.
- `assets/assessment/app.mjs`: 기본 JavaScript로 입력, 필수값 안내, 브라우저 저장, CSV 생성을 처리합니다. 추가 실행 라이브러리가 없습니다.
- `assets/assessment/app.css`: 자가 진단에 한정한 화면·모바일·테마 스타일
- `assets/gitbook/custom-local.js`: GitBook 메뉴 이동 시 중복 없이 화면 초기화
- `_includes/mathjax.html`: 기존 테마의 메뉴 이동 중 MathJax 중복 로드 방지

## 실행

`node --test tests/assessment.test.mjs`로 평가 규칙, 저장 형식, 이전 기록 변환, CSV 이스케이프와 전체 질문 포함 여부를 검사합니다.

정적 서버에서 `tests/assessment-preview.html`로 독립 입력 화면을 확인할 수 있습니다. 전체 Jekyll 검증은 `.github/workflows/validate-jekyll.yml`이 검토 브랜치 push 및 main 대상 PR에서 수행합니다. 생성 HTML·파일 경로·질문 개수, 평가 규칙, Chromium 메뉴 이동·입력 유지·CSV 다운로드·모바일·테마 전환을 검사합니다. 배포하지 않으며 결과물은 실행 페이지의 jekyll-site 아티팩트로 7일간 보관합니다. tests 디렉터리는 사이트 출력에서 제외합니다.

## 저장과 CSV

- 새 저장 키는 `gapzer0.assessment.<평가 질문 버전>.template-v2`입니다. 이전 키가 있으면 현재 입력만 읽어 옵니다. 이전 키와 이력은 수정하거나 삭제하지 않습니다.
- 저장 데이터의 버전, 질문 ID, 입력 형식과 길이를 확인합니다. 손상된 저장 내용은 덮어쓰지 않고 안내합니다. 저장 실패 상태에서도 메모리의 입력을 CSV로 내보낼 수 있습니다.
- CSV는 UTF-8 BOM, CRLF 행 구분, 모든 셀의 큰따옴표 처리, 큰따옴표 이중화로 생성합니다. 필터와 무관하게 작성 내용 CSV는 입력한 질문만, 빈 템플릿 CSV는 전체 489행을 출력합니다. 두 파일 모두 24열입니다. 응답을 선택하지 않은 초안도 포함하며, 열람만 했거나 입력을 모두 지운 질문은 제외합니다. 질문 입력이 없으면 작성 내용 다운로드 대신 안내합니다.
- 수식 시작 문자와 선행 제어문자에는 CSV에서만 보이는 `[텍스트] ` 접두어를 붙입니다. 브라우저 원문은 바꾸지 않습니다. CSV 수식 실행 위험과 범용 이스케이프의 한계는 [OWASP CSV Injection](https://owasp.org/www-community/attacks/CSV_Injection)을 참고합니다.
- 사용자 입력은 textContent/value로만 표시하며 HTML로 해석하지 않습니다. 입력은 서버로 전송하지 않습니다. 같은 사이트에서 실행되는 다른 스크립트는 브라우저 저장소를 읽을 수 있으므로 기존 테마와 외부 스크립트의 관리도 필요합니다.
- 평가 질문 목록·코드·CSS는 동일 출처 정적 파일입니다. 증적 링크 입력은 텍스트로 보관하며 실행하지 않습니다. 새 라이브러리나 백엔드를 추가하지 않습니다.

## 수동 확인

다섯 응답별 필수 조건, 미충족의 증적 없음 사유, 확인 필요의 추가 확인 계획, 조치 완료일·결과·증적을 확인합니다. 조치 완료가 응답을 자동으로 변경하지 않아야 합니다. CSV를 일반 스프레드시트에서 열어 한글과 여러 줄 증적의 표시를 확인합니다. CSV의 특성상 병합·색상·드롭다운은 제공하지 않습니다.

# GapZer0 Guideline AI Skill 기능 명세 v0.1

## 목적
GapZer0 가이드라인을 근거로 실무자가 관련 Control을 찾고, 이행계획과 실무 문서 초안을 작성하도록 지원한다.

## 기능 1. 관련 Control 안내
**입력:** 사용자의 업무 상황 또는 보안 요구사항  
**처리:** 요청 분석 → 인덱스 후보 검색 → Control 원문 확인 → 적용 조건 비교  
**출력:** ID·Name·관련 이유·적용 조건·주요 이행사항·추가 확인사항·원문 위치  
**범위:** 통제 후보와 근거를 안내하며 최종 인증·충족 판정을 수행하지 않는다.

## 기능 2. Control 이행계획
**입력:** 대상 업무 또는 Control ID, 조직 환경, 현재 운영 방식  
**처리:** Objective/Statement/적용 조건/Owner/Stakeholders/Implementation Guide/Evidence 확인 → 실행계획 구성  
**출력:** 실행 활동·담당 역할·협업 역할·시점·Evidence·추가 결정사항  
**범위:** 이행계획 초안을 지원하며 원문에 없는 조직별 값을 임의로 확정하지 않는다.

## 기능 3. 실무 문서 초안
**입력:** 문서 종류, 대상 업무 또는 Control, 조직 정보  
**처리:** 관련 Control 원문 확인 → 요구사항 추출 → 문서 구조에 맞게 재구성  
**출력:** 목적·범위·역할과 책임·절차·기록/Evidence·검토 방식·관련 Control  
**범위:** 정책·절차·계획·체크리스트 등의 초안을 지원한다.

## 공통 처리 흐름
사용자 요청 → 요청 유형 파악 → 필요한 조직 정보 확인 → control-index 검색 → Control 원문 확인 → 적용 조건 비교 → 결과 작성 → 근거 표시 → 미확정 사항 분리

## 공통 원칙
- 필요한 정보만 추가로 질문한다.
- 인덱스는 검색용이며 최종 근거는 Control 원문이다.
- 존재하지 않는 Control이나 Mapping을 만들지 않는다.
- 조직 정보는 추정하지 않는다.
- Evidence 예시를 실제 확보된 증적으로 표현하지 않는다.
- 가이드라인 근거, AI 제안, 확인 필요, 조직 결정 필요를 구분한다.
- 최종 인증 가능 여부나 컴플라이언스 충족 여부를 자동 판정하지 않는다.

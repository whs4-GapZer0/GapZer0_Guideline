Information Protection - Local Controls

Information Protection - Local Controls

INF-L-01

Control Name

개인정보 수집 제한

Security Domain

Information Protection

Control Class

Local

Control Objective

개인정보를 처리 목적에 필요한 최소한의 범위에서 적법하게 수집하고 불필요하거나 과도한 개인정보 수집을 방지합니다.

Control Statement

수집 목적과 항목의 필요성을 검토하지 않으면 편의를 이유로 불필요한 개인정보를 축적하여 침해 영향과 법적 책임이 커질 수 있습니다. 조직은 수집 전 적법한 근거, 목적, 최소 항목, 보유기간과 고지·동의 사항을 확인해야 합니다.

적용 조건

적용 시점

신규 서비스·업무·서식·화면을 설계하거나 개인정보 수집 목적·항목·방법·보유기간을 변경할 때 적용합니다.

적용 대상

웹·앱·서면·전화·기기·제3자 제공 등 모든 경로의 개인정보 수집과 이를 설계·승인·운영하는 부서·시스템에 적용합니다.

관련 법령

  • 「개인정보 보호법」 제15조 — 개인정보를 수집·이용할 수 있는 적법한 근거와 고지사항을 규정합니다.
  • 「개인정보 보호법」 제16조 — 처리 목적에 필요한 최소한의 개인정보만 수집하도록 규정합니다.

Control Owner

개인정보 수집업무 책임자 / 개인정보보호책임자

Stakeholders

서비스·업무 기획 담당자, 법무 담당자, 개인정보보호 담당자, 개발·운영 담당자, 마케팅 담당자, 고객지원 담당자, 내부감사 담당자

매핑된 ISMS-P 항목

  • 3.1.2 개인정보의 수집 제한

매핑된 CSF 항목

  • N/A — NIST CSF 2.0에 직접 대응하는 항목이 없는 국내 법·제도 기반 Control입니다.

Implementation Guide

1. 수집 목적과 적법한 근거를 확인하기

업무 목적, 법적 근거 또는 동의 필요 여부, 정보주체 유형과 처리 흐름을 확인하고 목적을 구체적으로 기록합니다.

2. 최소 수집항목을 정하기

각 항목이 목적 달성에 필요한지 검토하고 선택정보와 필수정보를 구분하며 불필요한 자유입력·사본 수집을 제거합니다.

3. 고지·동의와 수집화면을 검토하기

수집 목적, 항목, 보유기간, 거부권과 불이익을 알기 쉽게 제공하고 동의가 필요한 경우 다른 사항과 구분하여 받습니다.

4. 수집현황을 점검하고 불필요한 항목을 정리하기

실제 수집값과 사용현황을 정기 검토하여 목적과 무관하거나 장기간 사용하지 않는 항목의 수집을 중단하고 기존 데이터를 처리합니다.

Evidence

  • 개인정보 수집 목적·항목 검토서: 개인정보 수집 목적과 적법한 근거 및 항목별 필요성 검토 내용을 확인합니다.
  • 최소수집 판단·필수/선택 항목 승인 기록: 목적 달성에 필요한 수집항목과 필수·선택 구분의 판단·승인 내용을 확인합니다.
  • 수집화면·서식·고지·동의 문안: 수집 목적·항목·보유기간과 거부권 등의 고지 및 동의 문안을 확인합니다.
  • 정기 수집현황 점검·항목 축소 기록: 실제 수집·사용 현황의 정기 점검과 불필요한 항목의 수집 중단·정리 내역을 확인합니다.

INF-L-02

Control Name

민감정보 및 고유식별정보의 처리 제한

Security Domain

Information Protection

Control Class

Local

Control Objective

민감정보와 고유식별정보를 법령이 허용하거나 별도 동의를 받은 경우에만 최소한으로 처리하고 강화된 보호조치를 적용합니다.

Control Statement

건강정보·생체정보·주민등록번호 등은 유출되거나 오용될 경우 정보주체에게 큰 피해를 줄 수 있습니다. 조직은 처리 전 정보 유형과 적법한 근거를 확인하고 별도 동의, 암호화, 접근제한과 처리기록 등 강화된 Control을 운영해야 합니다.

적용 조건

적용 시점

민감정보·고유식별정보를 새로 수집·이용·제공하거나 처리 목적·항목·시스템·수탁자·보유기간을 변경할 때 적용합니다.

적용 대상

민감정보, 고유식별정보와 이를 수집·저장·조회·이용·제공·파기하는 업무, 시스템, 임직원·수탁자에 적용합니다.

관련 법령

  • 「개인정보 보호법」 제23조 — 민감정보의 처리 요건과 안전성 확보조치를 규정합니다.
  • 「개인정보 보호법」 제24조 — 고유식별정보의 처리 요건과 암호화 등 안전조치를 규정합니다.
  • 「개인정보의 안전성 확보조치 기준」 제7조 — 저장·전송되는 개인정보에 대한 암호화 조치를 규정합니다.

Control Owner

개인정보보호책임자 / 해당 업무책임자

Stakeholders

법무 담당자, 개인정보보호 담당자, 정보보호 담당자, 업무·서비스 기획 담당자, 개발·DB 운영 담당자, 수탁자, 내부감사 담당자

매핑된 ISMS-P 항목

  • 3.1.4 민감정보 및 고유식별정보의 처리 제한

매핑된 CSF 항목

  • N/A — NIST CSF 2.0에 직접 대응하는 항목이 없는 국내 법·제도 기반 Control입니다.

Implementation Guide

1. 정보 유형과 처리 근거를 확인하기

민감정보·고유식별정보 해당 여부, 법령상 허용 근거 또는 별도 동의 필요 여부와 목적·항목·보유기간을 확인합니다.

2. 처리 범위와 접근자를 최소화하기

목적 달성에 필요한 항목과 처리단계만 승인하고 취급자·관리자 권한을 최소화하여 정기적으로 검토합니다.

3. 강화된 보호조치를 적용하기

저장·전송 암호화, 암호키 관리, 강한 인증, 화면·출력 제한, 접속기록과 이상행위 점검을 적용합니다.

4. 변경·제공·보유·파기를 관리하기

목적·항목·제공처·수탁자 변경 시 근거와 동의를 다시 확인하고 보유기간 종료 시 안전하게 파기합니다.

Evidence

  • 민감정보·고유식별정보 처리 목록: 민감정보·고유식별정보의 처리 목적, 항목과 보유기간을 확인합니다.
  • 법적 근거·별도 동의·승인 기록: 처리의 법적 근거 또는 별도 동의와 처리 범위의 승인 내용을 확인합니다.
  • 암호화·권한·접속기록·출력통제 설정: 암호화, 접근권한, 접속기록과 화면·출력 제한의 적용 상태를 확인합니다.
  • 제공·위탁·변경·보유·파기 기록: 제공·위탁·변경에 따른 근거·동의 검토와 보유기간 종료 후 파기 내역을 확인합니다.

INF-L-03

Control Name

처리목적 달성 후 개인정보 보유 시 조치

Security Domain

Information Protection

Control Class

Local

Control Objective

처리 목적이 달성된 개인정보를 원칙적으로 지체 없이 파기하고, 다른 법령에 따라 보존해야 하는 경우에는 근거·기간을 확인하여 별도로 저장·관리합니다.

Control Statement

목적이 끝난 개인정보를 일반 운영데이터와 함께 계속 보관하면 무단 이용과 유출 위험이 커집니다. 조직은 목적 달성 여부를 식별하고 법정 보존대상만 분리·접근 제한하며 보존기간이 끝나면 안전하게 파기해야 합니다.

적용 조건

적용 시점

계약 종료, 회원 탈퇴, 서비스 종료, 보유기간 만료 등 처리 목적 달성 시점과 법정 보존기간의 시작·종료 시 적용합니다.

적용 대상

처리 목적을 달성한 개인정보와 백업·복제본·문서·저장매체, 법령에 따라 추가 보존하는 개인정보와 관련 시스템·담당자에 적용합니다.

관련 법령

  • 「개인정보 보호법」 제21조 — 보유기간 경과 또는 처리 목적 달성 시 개인정보를 파기하고, 법령에 따라 보존할 때에는 분리하여 저장·관리하도록 규정합니다.

Control Owner

개인정보 파기·보유 책임자

Stakeholders

개인정보보호 담당자, 법무·컴플라이언스 담당자, 업무부서, 시스템·DB 운영 담당자, 기록관리 담당자, 수탁자, 내부감사 담당자

매핑된 ISMS-P 항목

  • 3.4.2 처리목적 달성 후 보유 시 조치

매핑된 CSF 항목

  • N/A — NIST CSF 2.0에 직접 대응하는 항목이 없는 국내 법·제도 기반 Control입니다.

Implementation Guide

1. 목적 달성과 보유기간 만료를 식별하기

업무 이벤트와 개인정보 목록·보유기간을 연결하여 파기 또는 법정 보존 검토 대상을 적시에 생성합니다.

2. 추가 보존의 법적 근거와 기간을 확인하기

관련 법령, 보존 대상 항목, 목적, 기간과 책임자를 확인하고 내부 편의만으로 보존기간을 연장하지 않습니다.

3. 보존 대상 개인정보를 분리·제한하기

일반 이용 데이터와 논리적·물리적으로 분리하고 법정 목적에 필요한 최소 인원만 접근하도록 권한과 이용기록을 관리합니다.

4. 보존기간 종료 후 안전하게 파기하기

운영본·복제본·문서·매체와 가능한 백업 반영시점을 확인하여 복구하기 어려운 방법으로 파기하고 결과를 기록합니다.

Evidence

  • 개인정보 보유기간·목적달성 관리대장: 목적 달성과 보유기간 만료에 따른 파기·법정 보존 검토 대상의 식별 내용을 확인합니다.
  • 법정 보존 근거·항목·기간 검토서: 추가 보존의 법적 근거, 대상 항목과 보존기간의 검토 내용을 확인합니다.
  • 분리 저장·접근권한·이용기록: 법정 보존 대상의 분리 저장, 접근 제한과 이용 내역을 확인합니다.
  • 파기 승인·결과·백업 반영 기록: 파기 승인과 실행 결과 및 백업 반영 내역을 확인합니다.

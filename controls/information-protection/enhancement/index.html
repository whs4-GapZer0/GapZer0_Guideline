Information Protection - Enhancement Controls

Information Protection - Enhancement Controls

INF-E-01

Control Name

전송 데이터 기밀성·무결성·가용성

Security Domain

Information Protection

Control Class

Enhancement

Control Objective

네트워크와 외부 연계를 통해 전송되는 데이터의 기밀성·무결성·가용성을 보호하여 도청·변조·오배송과 전송 중단 위험을 줄입니다.

Control Statement

전송구간 암호화만으로는 수신자 확인, 데이터 변조 탐지와 채널 장애에 따른 가용성을 모두 보장하기 어렵습니다. 조직은 전송 경로와 데이터 중요도를 파악하고 안전한 통신, 송·수신자 인증, 무결성 검증, 오류·재전송과 대체경로를 함께 관리해야 합니다.

적용 조건

적용 시점

데이터 전송, API·시스템 연계, 파일교환, 전자거래, 원격접속과 외부 제공 경로를 신설·변경하거나 전송 장애·보안사고를 점검할 때 적용합니다.

적용 대상

내부망·인터넷·전용회선·무선망·클라우드·API·전자우편·파일전송 등으로 이동하는 개인정보·중요정보·업무데이터와 관련 통신서비스에 적용합니다.

관련 법령

  • 「개인정보 보호법」 제29조 — 개인정보 유출 등을 방지하기 위한 기술적·관리적·물리적 안전조치 의무를 규정합니다.
  • 「개인정보의 안전성 확보조치 기준」 제7조 — 저장·전송되는 개인정보에 대한 암호화 조치를 규정합니다.

Control Owner

정보전송 보안책임자 / 네트워크 운영책임자

Stakeholders

데이터·서비스 소유자, 정보보호 담당자, 개인정보보호 담당자, 개발·API 운영 담당자, 네트워크·클라우드 운영 담당자, 공급자

매핑된 ISMS-P 항목

  • 2.10.4 전자거래 및 핀테크 보안
  • 2.10.5 정보전송 보안
  • 2.7.1 암호정책 적용
  • 2.7.2 암호키 관리

매핑된 CSF 항목

  • PR.DS-02 — The confidentiality, integrity, and availability of data-in-transit are protected.

전송 중인 데이터가 도청·변조·중단되지 않도록 기밀성·무결성·가용성을 보호하는 Outcome입니다.

Implementation Guide

1. 전송 경로와 보호 요구를 파악하기

송·수신자, 데이터 유형·민감도, 경로, 프로토콜, 외부 제공·위탁 여부와 기밀성·무결성·가용성 요구를 기록합니다.

2. 안전한 통신과 인증을 적용하기

검증된 암호통신, 상호 인증, 안전한 키·인증서 관리와 허용된 경로를 적용하고 평문·비인가 전송을 제한합니다.

3. 무결성과 전송 가용성을 확보하기

전자서명·메시지 인증 등으로 변조를 확인하고 오류탐지, 재전송, 중복방지, 대체경로와 장애대응 절차를 운영합니다.

4. 전송 상태를 점검하고 사고에 대응하기

암호 설정, 인증서 만료, 실패·지연·변조 경보와 전송기록을 점검하고 노출·오배송·중단 발생 시 차단·통지·복구합니다.

Evidence

  • 데이터 전송경로·인터페이스 목록: 송·수신 대상, 데이터 유형과 네트워크·외부 연계의 전송 경로를 확인합니다.
  • 암호통신·인증서·키·접근통제 설정: 암호통신, 인증서·키 관리와 허용된 전송 경로의 접근통제 상태를 확인합니다.
  • 무결성 검증·재전송·대체경로 시험 결과: 변조 확인, 재전송과 대체경로를 통한 전송 가용성의 시험 결과를 확인합니다.
  • 전송 로그·오류·장애·사고 조치 기록: 전송 실패·지연·변조 등 오류와 사고에 대한 점검·조치 내역을 확인합니다.

ISMS-P Limitation

ISMS-P 2.10.5는 정보전송 절차와 채널 보호를, 2.7.1·2.7.2는 암호화와 암호키 관리를, 2.10.4는 전자거래·외부 연계 보호를 다룹니다. 다만 전송 데이터의 무결성 검증과 전송 서비스 가용성을 하나의 결과로 관리하는 요구는 충분히 통합되어 있지 않습니다.

CSF Coverage

이 Control은 안전한 통신과 송·수신자 인증뿐 아니라 전자서명·메시지 인증, 오류·재전송, 대체경로와 장애대응을 함께 요구하여 전송 데이터의 기밀성·무결성·가용성을 포괄하는 PR.DS-02 Outcome을 보완합니다.

INF-E-02

Control Name

Data-in-Use 보호

Security Domain

Information Protection

Control Class

Enhancement

Control Objective

조회·처리·연산 등 사용 중인 데이터가 권한 없는 사람이나 프로그램에 노출·변조되거나 처리 중단으로 사용할 수 없게 되는 위험을 줄입니다.

Control Statement

저장·전송 암호화를 적용해도 데이터는 처리 순간 메모리와 응용프로그램에서 복호화되어 노출될 수 있습니다. 조직은 사용 중 데이터(Data-in-Use)의 접근범위, 화면·메모리·임시파일, 처리 로직과 실행환경을 보호하고 이상행위를 탐지해야 합니다.

적용 조건

적용 시점

개인정보·중요정보를 조회·분석·변환·연산하는 기능을 설계·개발·운영하거나 처리 로직·권한·실행환경이 변경될 때 적용합니다.

적용 대상

응용프로그램, 데이터베이스 조회·처리, 분석·인공지능 작업, 메모리·캐시·임시파일, 가상화·클라우드 실행환경과 관리자·개발자 접근에 적용합니다.

관련 법령

  • 「개인정보 보호법」 제29조 — 개인정보 유출 등을 방지하기 위한 기술적·관리적·물리적 안전조치 의무를 규정합니다.

Control Owner

애플리케이션·데이터 보안책임자

Stakeholders

데이터·업무 소유자, 개인정보보호 담당자, 정보보호 담당자, 개발·운영 담당자, DB·클라우드 운영 담당자, 내부감사 담당자

매핑된 ISMS-P 항목

  • 2.6.3 응용프로그램 접근
  • 2.6.4 데이터베이스 접근
  • 3.2.2 개인정보 품질보장
  • 3.2.5 개인정보 목적 외 이용 및 제공

매핑된 CSF 항목

  • PR.DS-10 — The confidentiality, integrity, and availability of data-in-use are protected.

조회·처리·연산 등 사용 중인 데이터의 기밀성·무결성·가용성을 보호하는 Outcome입니다.

Implementation Guide

1. 사용 중 데이터와 처리위험을 파악하기

조회·처리 기능, 데이터 항목, 사용자·프로그램 권한, 메모리·임시저장 위치와 대량처리·분석 등 고위험 작업을 식별합니다.

2. 필요한 범위로 접근과 노출을 제한하기

역할별 최소 권한, 중요 기능 재인증, 화면 마스킹, 조회·다운로드 제한과 목적 외 이용 방지 절차를 적용합니다.

3. 처리 중 데이터와 실행환경을 보호하기

안전한 메모리 처리, 임시파일 보호·삭제, 프로세스 격리, 입력값·처리결과 무결성 검증과 중요 작업의 승인·분리를 적용합니다.

4. 이상행위와 가용성을 확인하기

대량조회·비정상 처리·권한오류·무단 변경을 모니터링하고 처리 중단 시 재개·복구하며 보호조치의 효과를 시험합니다.

Evidence

  • 사용 중 데이터 처리흐름·위험평가: 조회·처리 기능, 데이터 항목과 메모리·임시저장 위치의 처리위험을 확인합니다.
  • 역할별 권한·화면 마스킹·기능통제 설정: 역할별 접근권한, 화면 마스킹과 조회·다운로드 등 기능 제한의 적용 상태를 확인합니다.
  • 메모리·임시파일·프로세스 보호 설정과 시험결과: 메모리·임시파일·프로세스 보호조치의 설정과 효과 시험 결과를 확인합니다.
  • 대량조회·이상처리·중단·복구 기록: 대량조회·비정상 처리의 모니터링 결과와 처리 중단 시 재개·복구 내역을 확인합니다.

ISMS-P Limitation

ISMS-P 2.6.3·2.6.4는 응용프로그램과 데이터베이스 접근통제를, 3.2.2·3.2.5는 개인정보 정확성과 목적 외 이용 제한을 다룹니다. 다만 메모리·연산·임시처리 중인 데이터의 기밀성·무결성·가용성을 포괄하는 명시적 Control은 제한적입니다.

CSF Coverage

이 Control은 접근·화면 노출 제한, 메모리·임시파일·프로세스 보호, 처리결과 무결성 검증, 이상행위 탐지와 중단 복구를 함께 요구하여 사용 중 데이터의 기밀성·무결성·가용성을 다루는 PR.DS-10 Outcome을 보완합니다.

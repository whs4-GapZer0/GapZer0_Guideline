Information Security Assurance - Common Controls

Information Security Assurance - Common Controls

ISA-C-01

Control Name

위험관리 성과 평가·검토

Security Domain

Information Security Assurance

Control Class

Common

Control Objective

사이버보안 위험관리 활동과 보호조치의 성과를 일관된 지표와 근거로 평가하고 경영진이 필요한 조정사항을 검토하도록 합니다.

Control Statement

점검 수행 여부만 확인하면 위험 감소, 사고 예방과 개선 효과를 판단하기 어렵습니다. 조직은 목표와 위험에 맞는 성과지표를 정하고 운영·사고·점검 데이터를 분석하여 Control 효과, 반복 문제와 자원 조정 필요성을 평가해야 합니다.

적용 조건

적용 시점

정기 관리체계 점검, 경영진 검토, 연간 계획·예산 수립과 주요 사고·환경 변화 후 성과를 재평가할 때 적용합니다.

적용 대상

관리체계 범위의 위험관리 목표, 정책·Control, 개선과제, 사고·취약점·교육·공급자 등 주요 보안활동과 책임부서에 적용합니다.

관련 법령

  • 「개인정보 보호법」 제29조 — 개인정보 유출 등을 방지하기 위한 기술적·관리적·물리적 안전조치 의무를 규정합니다.
  • 「개인정보의 안전성 확보조치 기준」 제4조 — 내부 관리계획의 수립·시행과 이행 실태 점검에 필요한 사항을 규정합니다.

Control Owner

정보보호 최고책임자 / 성과평가 책임자

Stakeholders

경영진, 위험관리 담당자, 개인정보보호 담당자, 내부감사 담당자, IT·보안운영 담당자, 각 Control 책임부서

매핑된 ISMS-P 항목

  • 1.4.2 관리체계 점검
  • 1.3.3 운영현황 관리

매핑된 CSF 항목

  • GV.OV-03 — Organizational cybersecurity risk management performance is evaluated and reviewed for adjustments needed.

조직의 사이버보안 위험관리 성과를 평가하고 필요한 조정사항을 검토하는 Outcome입니다.

Implementation Guide

1. 성과 목표와 지표를 정하기

조직 목표와 주요 위험에 연결된 핵심성과지표와 핵심위험지표, 산식, 데이터 출처, 목표·경고수준과 책임자를 정합니다.

2. 신뢰할 수 있는 성과자료를 수집하기

위험등록부, 사고·취약점, Control 운영, 교육, 공급자, 개선과제의 데이터를 정기적으로 취합하고 누락·중복·정확성을 확인합니다.

3. 성과와 Control 효과를 평가하기

목표 대비 결과, 위험 추세, 반복 문제, 미완료 과제와 Control의 실제 위험 감소 효과를 분석합니다.

4. 경영진이 조정사항을 검토·결정하기

평가 결과를 보고하여 전략·정책·Control·자원·우선순위의 유지 또는 조정을 결정하고 후속과제를 추적합니다.

Evidence

  • 사이버보안 성과지표·산식·목표: 조직 목표·위험에 연결된 성과·위험지표의 산식, 출처와 목표 수준을 확인합니다.
  • 성과 데이터·추세·Control 효과 분석자료: 수집된 성과자료, 위험 추세와 Control의 위험 감소 효과에 대한 분석 결과를 확인합니다.
  • 정기 점검·경영진 검토 보고서와 회의록: 성과평가 결과의 정기 보고와 경영진 검토 내용을 확인합니다.
  • 전략·Control·자원 조정 결정 및 추적 기록: 전략·Control·자원 등의 유지·조정 결정과 후속과제 추적 내역을 확인합니다.

ISA-C-02

Control Name

평가에서 개선사항 식별

Security Domain

Information Security Assurance

Control Class

Common

Control Objective

내부·외부 평가 결과에서 Control 미흡과 개선기회를 체계적으로 식별하고 원인·위험·우선순위에 따라 개선조치를 완료하여 재발을 방지합니다.

Control Statement

평가 결과가 보고서에만 남으면 같은 문제가 반복됩니다. 조직은 평가에서 발견된 부적합·관찰사항·개선기회를 하나의 절차로 등록하고 원인을 분석하여 책임자·기한·검증방법이 포함된 조치를 수행해야 합니다.

최고경영자(CEO)와 경영진은 점검·감사 개선 결과의 정확성과 효과성을 검토하고 중대한 개선 사항을 승인합니다. 정보보호 개선관리 책임자와 내부감사 책임자는 실무 수행·보고 및 승인사항의 이행 책임을 유지합니다.

적용 조건

적용 시점

관리체계 점검, 내부감사, 인증심사, 법규 준수검토, Control 효과성 평가와 경영진 검토 결과가 나온 때 적용합니다.

적용 대상

평가에서 식별된 부적합, 취약점, 반복 문제, 미달 지표와 개선기회 및 관련 Control·부서·시스템에 적용합니다.

관련 법령

  • 「개인정보 보호법」 제29조 — 개인정보 유출 등을 방지하기 위한 기술적·관리적·물리적 안전조치 의무를 규정합니다.
  • 「개인정보의 안전성 확보조치 기준」 제4조 — 내부 관리계획의 수립·시행과 이행 실태 점검에 필요한 사항을 규정합니다.

Control Owner

정보보호 개선관리 책임자 / 내부감사 책임자

Stakeholders

최고경영자(CEO), 경영진, Control 책임부서, 위험관리 담당자, 개인정보보호 담당자, IT·보안운영 담당자, 법무·컴플라이언스 담당자

매핑된 ISMS-P 항목

  • 1.4.3 관리체계 개선
  • 1.4.2 관리체계 점검

매핑된 CSF 항목

  • ID.IM-01 — Improvements are identified from evaluations.

평가 결과에서 관리체계와 보호조치의 개선사항을 찾아내는 Outcome입니다.

Implementation Guide

1. 평가 결과를 통합하여 등록하기

평가 출처, 문제·근거, 영향받는 자산·업무, 관련 기준과 책임부서를 기록하고 중복 항목을 연결합니다.

2. 원인과 위험을 분석하기

표면적인 증상뿐 아니라 절차·인력·기술·관리의 근본원인과 발생 가능성·영향을 평가합니다.

3. 개선조치를 수립·승인하기

위험과 시급성에 따라 우선순위를 정하고 조치내용, 책임자, 완료 기한, 자원과 효과 확인방법을 승인합니다.

최고경영자(CEO)·경영진이 직접 검토·승인할 중대한 개선 사항과 담당 책임자가 승인할 수 있는 사항을 구분합니다. 정보보호 개선관리 책임자와 내부감사 책임자는 개선계획과 검증 결과를 보고하고, 최고경영자(CEO)·경영진은 결과의 정확성·효과성을 검토하여 중대한 개선 사항을 승인합니다. 검토 의견, 승인 내용과 후속 이행 결과를 기록합니다.

4. 완료와 효과를 검증하기

증적과 재점검으로 조치 이행과 재발방지 효과를 확인하고 미흡하면 추가조치를 요구한 뒤 권한 있는 책임자가 종결합니다.

Evidence

  • 평가결과·개선 사항 통합대장: 평가 출처, 발견 문제·근거, 관련 자산·업무와 책임부서의 통합 관리 내역을 확인합니다.
  • 원인·위험·우선순위 분석자료: 개선 사항의 근본원인, 발생 가능성·영향과 조치 우선순위 분석 결과를 확인합니다.
  • 개선계획·책임자·기한·승인 기록: 개선조치의 내용, 책임자, 완료 기한과 계획 승인 내역을 확인합니다.
  • 완료증적·재점검·효과성 검증 및 종결기록: 조치 완료와 재점검 결과, 재발방지 효과의 검증 및 종결 내역을 확인합니다.
  • 최고경영자(CEO)·경영진과 담당 책임자별 검토·승인 범위: 경영진이 직접 검토·승인할 중대한 사항과 담당 책임자의 승인 사항이 구분되어 있는지 확인합니다.
  • 개선 결과의 정확성·효과성 검토, 중대한 개선 사항 승인 및 후속 이행 기록: 경영진의 정확성·효과성 검토, 중대한 개선 사항 승인과 후속 이행 결과를 확인합니다.

ISA-C-03

Control Name

보안 시험·훈련에서 개선사항 식별

Security Domain

Information Security Assurance

Control Class

Common

Control Objective

보안 시험과 사고·재해 대응훈련 결과에서 기술·절차·협업의 미흡 사항을 식별하고 공급자·제3자를 포함한 개선조치와 재시험으로 실제 대응능력을 높입니다.

Control Statement

시험과 훈련을 실시했다는 사실만으로 보안수준이 향상되지는 않습니다. 조직은 목표와 합격기준을 정하고 실제와 유사한 시나리오로 시험·훈련한 뒤 발견사항, 의사결정, 협업과 복구 결과를 분석하여 개선해야 합니다.

적용 조건

적용 시점

취약점·침투·복구 시험, 사고대응·재해복구 모의훈련을 계획·수행한 후와 중요 시스템·공급자·위협이 변경될 때 적용합니다.

적용 대상

관리체계 범위의 기술 보안시험, 사고대응·복구·재해훈련, 참여 임직원과 필요한 공급자·수탁자·관계기관에 적용합니다.

관련 법령

  • 「개인정보 보호법」 제29조 — 개인정보 유출 등을 방지하기 위한 기술적·관리적·물리적 안전조치 의무를 규정합니다.
  • 「개인정보의 안전성 확보조치 기준」 제4조 — 내부 관리계획의 수립·시행과 이행 실태 점검에 필요한 사항을 규정합니다.
  • 「개인정보의 안전성 확보조치 기준」 제11조 — 적용 대상 개인정보처리자의 재해·재난 대응절차와 백업·복구 계획 수립 등을 규정합니다.

Control Owner

보안시험·훈련 책임자

Stakeholders

정보보호 담당자, 개인정보보호 담당자, 사고대응 담당자, 업무연속성 담당자, IT 운영 담당자, 개발 담당자, 공급자·수탁자, 내부감사 담당자

매핑된 ISMS-P 항목

  • 2.11.2 취약점 점검 및 조치
  • 2.11.4 사고 대응 훈련 및 개선
  • 2.12.2 재해 복구 시험 및 개선

매핑된 CSF 항목

  • ID.IM-02 — Improvements are identified from security tests and exercises, including those done in coordination with suppliers and relevant third parties.

보안 시험과 훈련, 공급자·제3자와 함께한 활동의 결과에서 개선사항을 찾아내는 Outcome입니다.

Implementation Guide

1. 시험·훈련 목표와 범위를 정하기

위험과 중요도를 바탕으로 대상, 시나리오, 참여자, 안전조치, 합격기준, 관찰자와 증적 수집방법을 정합니다.

2. 실제와 유사하게 수행하기

기술시험과 사고·재해 시나리오를 실행하고 필요한 공급자·제3자와 협력하여 탐지·의사결정·소통·복구 과정을 확인합니다.

3. 결과와 원인을 분석하기

합격기준 대비 결과, 지연·오류·협업문제, 발견된 취약점과 원인을 기록하고 실제 위험과 업무 영향을 평가합니다.

4. 개선하고 재시험하기

절차·기술·교육·계약 개선의 책임자와 기한을 정하고 중요한 미흡 사항은 재시험하여 효과를 확인합니다.

Evidence

  • 보안시험·훈련 계획·시나리오·합격기준: 시험·훈련의 대상, 시나리오, 참여자와 합격기준을 확인합니다.
  • 수행 로그·관찰기록·참여자·공급자 협업 기록: 시험·훈련 수행 과정과 관찰 결과, 참여자 및 공급자와의 협업 내역을 확인합니다.
  • 결과보고서·취약점·원인·위험평가: 합격기준 대비 결과, 발견된 취약점·원인과 위험·업무 영향의 평가 내용을 확인합니다.
  • 개선계획·완료증적·재시험 결과: 개선조치의 책임자·기한, 완료 증적과 재시험을 통한 효과 확인 결과를 확인합니다.

ISA-C-04

Control Name

운영 프로세스 수행에서 개선사항 식별

Security Domain

Information Security Assurance

Control Class

Common

Control Objective

일상 운영 프로세스와 절차의 수행 결과에서 오류·예외·반복 지연과 Control 실패를 찾아내고 지속적인 개선으로 연결합니다.

Control Statement

정기 평가만으로는 운영 중 발생하는 작은 실패와 비효율을 적시에 발견하기 어렵습니다. 조직은 운영기록, 예외, 장애, 문의, 변경과 지표를 검토하여 개선 신호를 식별하고 절차·도구·역할에 반영해야 합니다.

최고경영자(CEO)와 경영진은 운영활동과 개선 결과의 효과성을 정기적으로 검토합니다. 정보보호 운영개선 책임자는 실무 수행·보고 및 승인사항의 이행 책임을 유지합니다.

적용 조건

적용 시점

보안·IT 운영활동 수행 중 오류·예외·지연·장애·위반이 발생하거나 정기 운영현황과 성과를 검토할 때 적용합니다.

적용 대상

접근권한, 변경·패치, 백업, 로그, 취약점, 사고, 공급자, 개인정보 처리 등 관리체계 범위의 운영 프로세스·절차·활동에 적용합니다.

관련 법령

  • 「개인정보 보호법」 제29조 — 개인정보 유출 등을 방지하기 위한 기술적·관리적·물리적 안전조치 의무를 규정합니다.
  • 「개인정보의 안전성 확보조치 기준」 제4조 — 내부 관리계획의 수립·시행과 이행 실태 점검에 필요한 사항을 규정합니다.

Control Owner

정보보호 운영개선 책임자

Stakeholders

최고경영자(CEO), 경영진, 각 Control 책임부서, 개인정보보호 담당자, IT·보안운영 담당자, 서비스 소유자, 위험관리 담당자, 내부감사 담당자, 공급자

매핑된 ISMS-P 항목

  • 1.3.3 운영현황 관리
  • 1.4.3 관리체계 개선

매핑된 CSF 항목

  • ID.IM-03 — Improvements are identified from execution of operational processes, procedures, and activities.

일상 운영 프로세스·절차·활동의 수행 결과에서 개선사항을 찾아내는 Outcome입니다.

Implementation Guide

1. 운영활동과 예외를 기록하기

프로세스별 작업결과, 승인, 오류, 예외, 지연, 재작업, 장애와 사용자·운영자 의견을 추적 가능한 형태로 남깁니다.

2. 개선 신호와 반복 문제를 찾기

운영지표와 기록을 정기 검토하여 반복 실패, 병목, 수동작업, 책임 공백과 Control 우회 사례를 식별합니다.

3. 원인과 개선방안을 정하기

업무·기술·인력·공급자 원인을 분석하고 절차 단순화, 자동화, 역할 조정, 교육과 기술 개선방안을 우선순위화합니다.

4. 변경을 적용하고 효과를 확인하기

승인된 개선을 정책·절차·도구와 교육에 반영하고 이후 오류·지연·위험이 감소했는지 운영지표로 확인합니다.

최고경영자(CEO)·경영진의 정기 검토 주기·범위를 정하고, 개선조치 중 경영진이 직접 승인할 사항과 담당 책임자가 승인할 수 있는 사항을 구분합니다. 정보보호 운영개선 책임자는 운영현황과 개선 결과를 보고하고, 최고경영자(CEO)·경영진은 효과성을 정기적으로 검토합니다. 검토 의견과 기준에 따른 승인 결과를 기록하고 후속 조치의 이행 여부를 확인합니다.

Evidence

  • 운영활동·승인·예외·장애 기록: 운영 작업결과, 승인과 오류·예외·장애 등 발생 내역을 확인합니다.
  • 운영지표·반복문제·병목 분석자료: 운영지표와 기록에서 식별한 반복 실패·병목 등 개선 신호의 분석 결과를 확인합니다.
  • 원인분석·개선과제·승인 기록: 업무·기술·인력·공급자 원인 분석과 개선과제의 선정·승인 내용을 확인합니다.
  • 절차·도구 변경 이력과 개선효과 확인자료: 정책·절차·도구의 변경 내역과 오류·지연·위험 감소 여부의 확인 결과를 확인합니다.
  • 최고경영자(CEO)·경영진의 정기 검토 범위·주기와 개선조치별 승인권자·승인 범위: 경영진 정기 검토의 범위·주기와 개선조치별 승인권자 및 승인 범위의 구분을 확인합니다.
  • 운영활동·개선 결과의 효과성 검토, 승인 및 후속 이행 기록: 운영현황·개선 결과에 대한 효과성 검토, 승인과 후속 조치의 이행 내역을 확인합니다.

ISA-C-05

Control Name

사고대응 등 사이버보안 계획 수립·전달·유지·개선

Security Domain

Information Security Assurance

Control Class

Common

Control Objective

사고대응 계획과 운영에 영향을 주는 사이버보안 계획을 수립하고 관계자에게 전달하며 정기적으로 유지·개선하여 실제 상황에서 일관되게 실행할 수 있도록 합니다.

Control Statement

계획이 서로 분리되거나 담당자에게 전달되지 않으면 사고·재해 상황에서 중복·누락과 의사결정 지연이 발생합니다. 조직은 사고대응, 복구, 업무연속성, 위기소통 등 관련 계획의 관계를 정하고 변화·훈련·사고 결과를 반영해야 합니다.

적용 조건

적용 시점

관리체계 구축, 신규 서비스·중요 변경, 조직·공급자·법규·위협 변화, 정기 검토, 시험·훈련과 실제 사고 후 적용합니다.

적용 대상

사고대응, 재해복구, 업무연속성, 위기소통, 비상연락과 운영에 영향을 주는 기타 사이버보안 계획 및 관련 내부·외부 담당자에 적용합니다.

관련 법령

  • 「개인정보 보호법」 제29조 — 개인정보 유출 등을 방지하기 위한 기술적·관리적·물리적 안전조치 의무를 규정합니다.
  • 「개인정보 보호법」 제34조 — 개인정보 유출 사실의 통지와 신고에 필요한 사항을 규정합니다.
  • 「개인정보의 안전성 확보조치 기준」 제4조 — 내부 관리계획의 수립·시행과 이행 실태 점검에 필요한 사항을 규정합니다.
  • 「개인정보의 안전성 확보조치 기준」 제11조 — 적용 대상 개인정보처리자의 재해·재난 대응절차와 백업·복구 계획 수립 등을 규정합니다.

Control Owner

정보보호 최고책임자 / 사고대응·업무연속성 책임자

Stakeholders

경영진, 개인정보보호 담당자, IT·보안운영 담당자, 업무부서, 법무·홍보 담당자, 공급자·수탁자, 관계기관

매핑된 ISMS-P 항목

  • 2.11.1 사고 예방 및 대응체계 구축
  • 2.11.4 사고 대응 훈련 및 개선
  • 2.12.1 재해·재난 대비 안전조치

매핑된 CSF 항목

  • ID.IM-04 — Incident response plans and other cybersecurity plans that affect operations are established, communicated, maintained, and improved.

사고대응 계획과 운영에 영향을 주는 사이버보안 계획을 수립·전달·유지·개선하는 Outcome입니다.

Implementation Guide

1. 필요한 계획과 상호관계를 정하기

조직 위험과 업무영향을 바탕으로 사고대응·복구·연속성·소통 계획의 범위, 우선순위, 개시·전환 조건과 책임을 연결합니다.

2. 실행 가능한 계획을 수립·승인하기

역할, 연락망, 단계별 절차, 의사결정 권한, 자원, 외부 협력, 기록·보고와 종료조건을 포함하여 권한 있는 책임자가 승인합니다.

3. 계획을 전달하고 준비상태를 확보하기

관련 임직원·공급자에게 필요한 내용을 제공하고 교육·훈련, 연락망 확인과 자원 준비를 통해 역할 수행 가능성을 확인합니다.

4. 변화와 결과를 반영하여 유지·개선하기

조직·시스템·공급자·법규·위협 변화와 시험·훈련·사고 교훈을 검토하여 계획을 개정·재승인하고 버전과 배포이력을 관리합니다.

Evidence

  • 사고대응·복구·연속성·소통 계획 목록: 조직 위험과 업무 영향을 반영한 계획의 종류·범위와 상호관계를 확인합니다.
  • 승인된 계획과 계획 간 개시·전환 기준: 권한 있는 책임자의 계획 승인과 계획 간 개시·전환 조건의 연계를 확인합니다.
  • 교육·훈련·연락망·자원 준비 기록: 관련 임직원·공급자 대상 교육·훈련, 연락망 확인과 실행 자원의 준비 상태를 확인합니다.
  • 정기 검토·개정·승인·배포·버전 이력: 환경 변화와 훈련·사고 교훈에 따른 계획 검토·개정·재승인 및 배포 이력을 확인합니다.

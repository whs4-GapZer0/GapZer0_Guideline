04. Control 이행 안내

15개 보안 영역에서 조직에 필요한 Control을 찾아보세요.

영역을 선택하면 해당 Control과 구체적인 이행 방법을 확인할 수 있습니다.

보안 영역별 Control

  1. 01

    Governance

    경영진의 방향 설정과 역할·책임을 바탕으로 조직의 보안 전략과 위험관리를 이끕니다.

    →
  2. 02

    Asset Management

    정보자산을 식별·분류하고 소유자와 중요도를 정해 자산의 생애주기 전반을 관리합니다.

    →
  3. 03

    Continuity

    업무 중단에 대비하고 복구계획과 훈련을 통해 핵심 업무의 연속성을 확보합니다.

    →
  4. 04

    Human Resource Security

    입사·재직·퇴직 과정의 보안 책임과 교육을 통해 사람으로부터 발생하는 위험을 줄입니다.

    →
  5. 05

    Identity and Access Management

    사용자와 기기의 신원을 확인하고 업무에 필요한 접근권한을 부여·검토·회수합니다.

    →
  6. 06

    Information Protection

    정보의 저장·처리·전송 과정에서 기밀성과 무결성을 유지하고 유출과 훼손을 방지합니다.

    →
  7. 07

    Information Security Assurance

    독립적인 점검과 검증으로 보안 Control의 적절성과 이행 상태를 확인하고 개선합니다.

    →
  8. 08

    Information Security Event Management

    보안 이벤트를 탐지·분석하고 사고 대응과 후속 개선으로 피해와 재발 가능성을 줄입니다.

    →
  9. 09

    Legal and Compliance

    법률·규제·계약상 의무와 개인정보 처리 요구사항을 파악하고 준수 여부를 관리합니다.

    →
  10. 10

    Physical Security

    시설의 출입과 물리적 환경을 관리해 비인가 접근과 재해로부터 정보자산을 보호합니다.

    →
  11. 11

    Application Security

    애플리케이션의 설계·개발·시험·운영 과정에 보안을 반영해 소프트웨어 위험을 줄입니다.

    →
  12. 12

    Secure Configuration

    시스템과 서비스의 보안 설정 기준을 수립하고 변경과 점검을 통해 안전한 상태를 유지합니다.

    →
  13. 13

    Supplier Relationships Security

    공급자 선정부터 계약·서비스 운영·종료까지 외부 의존 관계의 보안 위험을 관리합니다.

    →
  14. 14

    System and Network Security

    시스템과 네트워크에 보호조치를 적용해 침입과 악성코드 확산을 막고 안전하게 운영합니다.

    →
  15. 15

    Threat and Vulnerability Management

    위협정보와 취약점을 식별·분석하고 위험도에 따라 조치 우선순위를 정해 보완합니다.

    →

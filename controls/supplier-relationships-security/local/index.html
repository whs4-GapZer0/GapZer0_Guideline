Supplier Relationships Security - Local Controls

Supplier Relationships Security - Local Controls

SUP-L-01

Control Name

영업의 양도 등에 따른 개인정보 이전

Security Domain

Supplier Relationships Security

Control Class

Local

Control Objective

영업양도·합병 등으로 개인정보가 이전될 때 정보주체에게 필요한 사항을 알리고 이전받는 자가 개인정보를 적법하게 처리하도록 관리합니다.

Control Statement

조직은 영업의 전부·일부 양도, 합병 등으로 개인정보를 이전하는 경우 이전 사실과 이전받는 자 등 법정 사항을 정보주체에게 알리고 안전한 이전과 후속 처리를 관리해야 합니다.

적용 조건

적용 시점

영업양도·합병 등 개인정보 이전이 예정될 때 적용합니다.

적용 대상

이전 대상 개인정보와 이전하는 자·이전받는 자에 적용합니다.

관련 법령

  • 「개인정보 보호법」 제27조 — 영업양도·합병 등에 따른 개인정보 이전 시 사전 통지와 이용목적 제한 등을 규정합니다.

Control Owner

개인정보보호책임자(CPO) / 개인정보보호 담당부서

Stakeholders

경영기획 담당자, 법무 담당자, M&A 담당자, 고객지원 담당자, 정보보호 담당자

매핑된 ISMS-P 항목

  • 3.3.3 영업양도 등에 따른 개인정보 이전

매핑된 CSF 항목

  • N/A

Implementation Guide

1. 이전범위·근거 확인

이전 대상 정보와 거래구조·법적 요건을 확인합니다.

2. 정보주체 통지

법정 사항·방법·시점에 따라 이전 사실을 알립니다.

3. 안전한 이전

전송·매체·권한을 통제하고 이전 전후 데이터 무결성과 접근을 관리합니다.

4. 이전 완료 검증

이전받는 자의 처리목적·보유·보호조치와 이전자의 잔존정보 처리를 확인합니다.

Evidence

  • 이전 대상·계획: 범위와 책임을 확인합니다.
  • 정보주체 통지 기록: 법정 통지 이행을 확인합니다.
  • 이전·인수 기록: 안전한 이전을 확인합니다.
  • 잔존정보·후속조치 기록: 이전 완료 후 위험처리를 확인합니다.
